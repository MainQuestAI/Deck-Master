# Deck Master v0.9.14-preview.3 Release Notes

日期：2026-08-10
状态：Technical Preview / agent-operable
公开版本：`v0.9.14-preview.3`
Python 包版本：`0.9.14a3`
Skill Suite 合同版本：`1.1.0`

## 发布摘要

本版本将 High-Density Builder 纳入可安装的 Deck Master Technical Preview。它沿用 CyberPPT 的 MBB 内容增强方法，并由 Deck Master 独立实现从内容锁、图片蓝图、原生 SVG 到可编辑 PPTX 的完整链路。

## 主要能力

- MBB 内容增强：故事线候选、用户选择、选中故事线丰富、SCR、证据绑定、逐页物料池和密度规划。
- 客户可见内容净化：页码、页面编号和未批准的内部分析标注在 ImageGen、SVG 和 PPTX 层均保持阻断。
- 蓝图到原生 SVG：保留文字、图标、曲线、表格和复杂视觉的语义登记与局部视觉检查。
- SVG 到 PPTX：approved SVG 作为几何和样式权威输入，生成原生 DrawingML group、trace 和 readback 证据。
- 图标稳定性：支持受控的 `symbol/use` 展开、多子路径、Bezier、arc、描边端点和连接样式，并对语义漂移 fail-closed。
- 术语迁移：当前运行时统一使用 MBB；退休过程件只能触发 `HD_MBB_MIGRATION_REQUIRED`，不能恢复进入完成态。

## 安装与升级

```bash
python3.12 -m pip install -e ".[dev]"
python3 scripts/deck_master.py suite-install --target codex --include-optional
```

安装后可通过以下命令确认 high-density capability：

```bash
deck-master agent-doctor --mode preview --output json
deck-master suite-status --capability deck_master.build.high_density.v1 --output json
```
