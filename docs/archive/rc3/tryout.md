## 目前能做什么

| 用户功能 | 当前情况 |
|---|---|
| 从材料开始，整理论证、大纲、逐页正文和口播稿 | 已有实现。可分别只做大纲、上屏稿、口播或完整内容；实际写作由接手工作单的制作工具执行。 |
| 导入已确认稿件，继续设计或修改 | 已有实现。保留原稿主线与映射，先检查保真，不强制重新写整稿。 |
| 设计要求、风格样页、选页制作与候选比较 | 已有实现。支持现场讲述、独立阅读的密度要求和关系约束；图片生成需要制作工具提供实际调用能力。 |
| SVG 转可编辑 PPTX、预览与口播备注 | 已有实现。文字与图形可编辑；表格和图表是形状组合。网页导出可选择 PPT 备注、独立口播稿、两者或纯阅读稿。 |
| 网页局改、版本比较、保存、导出和恢复 | 已有实现。未修改页保留；只改备注可保留适用原图与 SVG。 |
| CLI、网页和四个职责入口 | 已有实现。使用同一 Runtime；支持隔离安装、升级与回退。 |
| 没有独立审阅通道时继续普通前审 | 已补齐正常操作。用户可以明确选择当前制作工具自审，绑定当前请求和明确页集；默认独立审阅要求仍保留。 |
| 正常整套制作与局改预算 | 从真实已采用 Plan 或修改影响预览计算逐页首次调用上限，正式任务绑定逐页额度；重复授权保留已有消耗，未知调用仍需核实。 |
| 候选数量上限 | 正式试作按既有任务保留候选槽。达到上限后不再创建新槽，最后一个合法结果仍可接收、比较与按已有权限采用。 |

整稿检查由制作/审阅 Agent 对照任务、原材料和实际文件完成，包括内容、密度、关系、可读性、编辑性及所选讲稿。不要求用户组织听众反馈或真人计时；指定桌面软件仅在本次任务明确要求时适用。

## 打开工作台

可在新目录克隆试用分支，用 Python 3.11 或 3.12 建立隔离环境。这些命令由你在需要试用的机器执行：

```bash
git clone --branch main https://github.com/MainQuestAI/Deck-Master.git Deck-Master-rc3-tryout
cd Deck-Master-rc3-tryout
python3.12 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/deck-master workbench --registry "$PWD/tryout/projects.json" --no-open
```

若使用下载的 wheel，则在独立环境中安装该文件后执行同一个 `deck-master workbench` 命令即可。选择有访问权限的仓库账号；需要已安装的 Python 和 Git。上述方式打开工作台，不自动更改其他制作工具的配置。需要四个职责入口时，按[隔离安装说明](../../../skills/deck-master/references/installation.md)注册该候选的托管入口。

打开命令返回的网址。可先选择“打开只读示例”浏览界面；该示例不调用模型。然后新建自己的项目，填写用途和材料，或导入已有完整稿件。制作任务需复制要求给已接入的制作工具执行；网页本身不自动启动模型。

检查本机工具可用性：

```bash
deck-master doctor --step compose
deck-master doctor --step render
```

预览需要 LibreOffice、Poppler 和 `rsvg-convert`。缺工具时按实际诊断补齐，再继续预览；材料整理和代码开发可继续。

## 本轮补齐的操作

**选择口播保留方式**：进入“任务与交付 → 文件”，选择“口播稿保留方式”，再生成审阅包或正式交付包。生成结果显示实际方式；独立讲稿可直接下载。网络中断后的核实和重试保留原版本与原选择。内部工程包保留恢复原件。

**选择内容审阅方式**：打开“查看本次工作与范围 → 选择内容审阅方式”。默认要求实际独立审阅。确需自审时，明确选择“由当前制作工具自审”，填写本次原因并确认。它只适用于当前请求和列出的全部页面，不授予制作权限或增加预算；换请求或增减页面后需重新核对。正式交付的人类专业复核政策不受影响。

恢复独立审阅要求后，旧自审 PASS 不再用于放行生产。原本通过真实接收路径认证的独立审阅事实可以继续使用，不要求审阅通道一直在线。

**查看制作预算**：整套内容与 Plan 固定后，从“查看本次工作与范围 → 查看制作预算”检查页集和首次调用上限，再记录明确授权。局改先在选页制作或意见区预览修改影响，再点击“查看这次修改的制作预算”；无需手填内部方案编号。记录预算后点击“读取当前版本并重新预览修改”，核对范围后创建交接任务。保存授权、预览和交接均不会自行调用模型或图片工具。

预算只覆盖明确页集和图层。零页不会扩大为全部页；旧授权与新授权各自保持来源，已绑定任务不会借用别处的新额度。批次中的各任务沿用该批次实际检查的同一授权。

整套制作或直接修改的授权会明确说明允许在所列范围内更新当前稿。局部试作只返回候选；只有候选权限时，自动替换当前稿的任务会被拒绝。缩小既有数字额度后，旧父授权引用或重复计算预算都不能恢复原来的大额度。

**明确采用候选**：在单页比较中预览采用影响后点击“采用这个候选”，或在“任务与交付 → 待决定”选择并预览后点击“采用所选候选”。有有效采用权限时直接复用；仅有试作权限时会显示所选页、图层和零调用采用授权，确认后重新核对当前目标再采用。取消保留当前稿；新版本或撤权竞争仍须重新预览。采用不增加图片调用，也不代表质量通过。结果不明时先按原编号核实，不另建一次采用。

用户为已用过首次额度的页面明确追加独立重试额度后，新任务会选择能支付该页的授权；其他页的原首次额度继续保留。无追加时仍拒绝重试，已绑定旧任务不能改借新授权。

可以先导出审阅包来试读和核对，即使仍有未完成项；正式交付包继续检查真实文件与当前要求。
