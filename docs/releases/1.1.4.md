# 1.1.4 版本说明

状态：本说明随「升到 1.1.4」的发版 PR 一起合入，Rust `deck`、`deck-tools` 和 WebUI 的包版本均改为 `1.1.4`。`v1.1.4` 标签和 GitHub Release 在该 PR 合入后创建，是否已发布以 [GitHub Releases](https://github.com/MainQuestAI/Deck-Master/releases) 页为准。

## 1. 摘要

本版覆盖 `v1.1.3`（`718fdc01`，2026-11-12）之后至 `main` 的 `31ca2881`（[#361](https://github.com/MainQuestAI/Deck-Master/pull/361) 合入后），共 10 个已合入 PR：[#342](https://github.com/MainQuestAI/Deck-Master/pull/342)、[#353](https://github.com/MainQuestAI/Deck-Master/pull/353)、[#354](https://github.com/MainQuestAI/Deck-Master/pull/354)、[#355](https://github.com/MainQuestAI/Deck-Master/pull/355)、[#356](https://github.com/MainQuestAI/Deck-Master/pull/356)、[#357](https://github.com/MainQuestAI/Deck-Master/pull/357)、[#358](https://github.com/MainQuestAI/Deck-Master/pull/358)、[#359](https://github.com/MainQuestAI/Deck-Master/pull/359)、[#360](https://github.com/MainQuestAI/Deck-Master/pull/360)、[#361](https://github.com/MainQuestAI/Deck-Master/pull/361)。

本版定位为 **1.1.x 稳定加固补丁（W0）**：在合入项目格式 7 与内容质量门禁后，系统性消除数据静默丢失、路径穿越、Python 导入污染、EXIF 旋转导出拦截、本地服务安全与跨平台测试盲区等 P0/P1 隐患。

## 2. 主要变更

- **项目格式 6 → 7 与出稿审稿（#353）**：新增 `brief.decision`、`brief.concerns`、`brief.narrator`、`framing.storyline`、`pages[].kind`、`pages[].argument` 及整稿出稿审稿记录，打开旧格式 6 项目保持只读不写盘，首次保存再升级。
- **制作依据与 WebUI 格式 7 保护（#354, #355）**：`calculate_basis` 将素材投影为 `{id, file}`，元数据和新增页绑定不再触发既有页误过期；WebUI 冲突合并改为键级合并，避免丢弃 v7 字段，总览与历史对比补全 v7 字段呈现。
- **安全与运行隔离（#356, #357, #359）**：native plan 图片素材强制限定任务目录相对路径与 PNG/JPEG 格式；`deck-tools` 子进程以 `-P`、`PYTHONSAFEPATH=1`、临时 `cwd` 与可配置超时运行；本地 HTTP 服务增加防点击劫持头、8 MiB 请求体上限、JSON `Content-Type` 校验和 16 线程池，Vite 开发代理仅放行本机 Origin。
- **图像入口归一与解析器加固（#358, #361）**：新增 `deck-tools normalize-image` 在素材/生图/native 入口统一转正 EXIF 方向并校验最大像素；`deck-tools` 加固颜色/字体/Zip 炸弹上限、SVG 解析器层 DOCTYPE 防御与压缩弧线标志解析，并将纯 XML 回读测试纳入默认 PR CI。
- **跨平台开发体验（#360）**：修复 macOS `/var` 符号链接导致 `token-lint` 失败的问题，更新 `browser-smoke.mjs` 适配格式 7，并补齐开发文档与断链修复。
