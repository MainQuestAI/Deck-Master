# 1.1.3 版本说明

状态：本说明随「升到 1.1.3」的发版 PR 一起合入，Rust `deck`、`deck-tools` 和 WebUI 的包版本均改为 `1.1.3`。旧 Python 包 `deck-master` 已在本版从仓库删除（[#309](https://github.com/MainQuestAI/Deck-Master/pull/309)），不再单独编号。`v1.1.3` 标签和 GitHub Release 在该 PR 合入后另行创建，是否已发布以 [GitHub Releases](https://github.com/MainQuestAI/Deck-Master/releases) 页为准。本文不暗示 PyPI 上架。

谁该看：使用 Rust `deck`、本机 WebUI 或 Codex Skill 创作、审阅和修改方案的作者与维护者。安装与首跑见 [getting-started](../getting-started.md)，上一版见 [1.1.2 说明](1.1.2.md)。

## 1. 摘要

本版覆盖 `v1.1.2`（`1f61c28e`，2026-11-09）之后，到 `main` 的 `b62ce271`（[#340](https://github.com/MainQuestAI/Deck-Master/pull/340) 合入后）的改动，共 17 个已合入 PR：[#247](https://github.com/MainQuestAI/Deck-Master/pull/247)、[#270](https://github.com/MainQuestAI/Deck-Master/pull/270)、[#308](https://github.com/MainQuestAI/Deck-Master/pull/308)、[#309](https://github.com/MainQuestAI/Deck-Master/pull/309)、[#310](https://github.com/MainQuestAI/Deck-Master/pull/310)、[#320](https://github.com/MainQuestAI/Deck-Master/pull/320)、[#321](https://github.com/MainQuestAI/Deck-Master/pull/321)、[#322](https://github.com/MainQuestAI/Deck-Master/pull/322)、[#323](https://github.com/MainQuestAI/Deck-Master/pull/323)、[#324](https://github.com/MainQuestAI/Deck-Master/pull/324)、[#328](https://github.com/MainQuestAI/Deck-Master/pull/328)、[#333](https://github.com/MainQuestAI/Deck-Master/pull/333)、[#334](https://github.com/MainQuestAI/Deck-Master/pull/334)、[#335](https://github.com/MainQuestAI/Deck-Master/pull/335)、[#336](https://github.com/MainQuestAI/Deck-Master/pull/336)、[#339](https://github.com/MainQuestAI/Deck-Master/pull/339)、[#340](https://github.com/MainQuestAI/Deck-Master/pull/340)。

主要变化是：默认安装四个职责入口，并去掉兼容入口 `deck`；旧 Python 工作台和官方 `legacy-export` 从仓库删除；逐页 native 还原接到 `deck run` 与 `deck build`；交付时用真实渲染的 PNG 替换图标红叉占位，并补上原图过期、共用版式等警告。

这些是已合入的功能与修复，不代表作品视觉验收通过。升级时要注意的事项见第 2 节，未验证项见第 6 节。

## 2. 升级时要注意的

- **项目格式 4 → 5 → 6**：1.1.2 仍是格式 4。[#310](https://github.com/MainQuestAI/Deck-Master/pull/310) 把格式升到 5，[#324](https://github.com/MainQuestAI/Deck-Master/pull/324) 再升到 6。两次都只提升 `user_version`，保留历史数据与文件；格式 6 增加可选的 native 产物引用。用旧程序打开高版本项目时，会提示升级 deck，或拒绝打开。不提供原地降级，回退需要使用升级前保留的完整项目副本。
- **默认安装四个职责入口**：安装脚本默认把 `deck-master`、`deck-content`、`deck-design`、`deck-review` 四个职责目录链到 `~/.codex/skills`，不再安装 `deck` 入口；`--skills-root` 可更换目录，`--skill-dir` 已取消（[#308](https://github.com/MainQuestAI/Deck-Master/pull/308)）。再次安装会只移除指向本源的旧 `deck` 软链接，并将仅含三条托管链接的旧包装目录升级为整目录软链接；含用户文件的目录会保留并报冲突。若同名旧 Python 线入口仍占用安装位置，脚本在写入前退出并打印路径。
- **旧 Python 线与 `legacy-export` 已删除**：`src/deck_master/`、`skills/`、旧线测试和 `deck-master` 命令（含 `legacy-export`）已移出仓库，旧项目不再提供官方导出。已经存在的 `legacy-export.v1` 档案仍可用 Rust `deck import` 导入（[#309](https://github.com/MainQuestAI/Deck-Master/pull/309)）。
- **`deck put` 按原文存正文**：不再清理数字与汉字之间的空格，也不再去掉只垫在标点旁边的空格。`1 数据与身份`、`增长 50 %` 会原样保存。已存储的版本不会被改写。若再次提交以前会被剥空格的正文，该页的 `content` 以及原图、SVG、native 依据会随之更新（[#333](https://github.com/MainQuestAI/Deck-Master/pull/333)）。
- **`deck review add` 要求 `--method`**：不再默认 `human`。漏写时报错并列出 `self_check`、`other_model`、`human`。依赖旧默认值的脚本需显式传入 `--method`（[#320](https://github.com/MainQuestAI/Deck-Master/pull/320)）。
- **非默认安装前缀**：非默认 `--prefix` 不改登录 shell 的 `PATH`。新会话会先运行 `PATH` 上已有的 `deck`。安装副本的 `commands.md` 会写上这次的绝对路径；若 `command -v deck` 指向别处，安装结束时会打印那个路径（[#336](https://github.com/MainQuestAI/Deck-Master/pull/336)）。

## 3. 安装、职责入口与仓库清理

- **四个职责入口成为默认安装形态**：每个入口改为整个职责目录的软链接，目录内保留真实 `SKILL.md`，以及指向共用 `references/`、`assets/` 的相对链接，以便 Codex 发现这些技能。兼容入口 `deck`（`deck-skill/SKILL.md`）已删除（[#308](https://github.com/MainQuestAI/Deck-Master/pull/308)）。
- **删除旧 Python 工作台**：根目录包装、`rebuild.yml` 和只服务旧包的文件一并移除；根目录 `pip install -e .` 不再安装 `deck-master` 命令（[#309](https://github.com/MainQuestAI/Deck-Master/pull/309)）。
- **自包含安装布局**：`scripts/install.sh` 在 `<prefix>/share/deck/installations/` 下准备完整目录（CLI 与内嵌 WebUI、非 editable 的 deck-tools venv、四个职责 Skill 及共享资源），验证后切换 `<prefix>/share/deck/current` 指针；职责入口链接经由 current；升级保留旧目录。首次多入口迁移中断时，`entry-migrations` 保存已确认入口的迁移凭据，供同参数重试，成功后删除（[#310](https://github.com/MainQuestAI/Deck-Master/pull/310)）。
- **首跑样例**：删除已无法在当前主线上运行的旧线示例，新增合成样例 `examples/first-run/`（虚构茶品牌「云芽茶站 / Cloudsprig Tea」，中英材料各一份）。README 快速开始改为：安装，在 Codex 中用一句话指向该样例，再用 `deck serve` 查看第一份稿；手动命令仍见 `deck-skill/references/commands.md`（[#321](https://github.com/MainQuestAI/Deck-Master/pull/321)、[#335](https://github.com/MainQuestAI/Deck-Master/pull/335)）。真实 Host 从一句话跑到 `deck serve` 的端到端，本版不声称已通过。
- **历史归档包出仓**：把 57 MiB 的 `docs/history/main-62dfcfc5637f-documents.zip` 移出 git 工作树，原样保留为 [release asset](https://github.com/MainQuestAI/Deck-Master/releases/tag/docs-history-archive-20261030)；git 历史仍可检出该文件（[#247](https://github.com/MainQuestAI/Deck-Master/pull/247)）。
- **CI**：`actions/setup-node` 从 4 升到 7（[#270](https://github.com/MainQuestAI/Deck-Master/pull/270)）。

## 4. 编辑、回读与界面

[#310](https://github.com/MainQuestAI/Deck-Master/pull/310) 补齐编辑、制作依据、构建回读和安装方面的既有缺口：

- 新增 `GET /api/builds/{id}`，按需持久读取构建详情；workspace 仍只返回构建摘要。
- 嵌套 labels、footnotes、callouts 的子项进入文字回读；材料保留不可变原件副本，`deck material text` 返回该副本路径，原件缺失时为 null。
- 新 SVG 依据为 svg-v2，纳入 purpose、layout；历史依据保持兼容，原图过期单独显示。
- 三类编辑共用同一套 draft dirty 判断。
- 新增 `frontend/browser-smoke.mjs` 浏览器冒烟脚本；CI 新增独立 render job，安装渲染与字体依赖后运行 `pytest -m render`。

WebUI 样式把组件颜色收进 `--dm-*` 变量，并加上 token 检查；旧的 `/studio/`、`/v2/` 地址不可用，请使用 `deck serve` 打印的地址（[#322](https://github.com/MainQuestAI/Deck-Master/pull/322)）。服务端行为未改，这两个路径本来就返回 404。

## 5. 逐页 native 还原与交付

- **逐页还原**：用按页计划驱动的 pptxgenjs 生成器、只走文件接口的 Python 适配器，以及随附的 Tabler outline 图标库，替换「已采用原图 → 可编辑 PPTX」这一步。内容策划、出图和采用原图的路径不变；只有 SVG 产物的旧稿仍走原来的 SVG 路径（[#323](https://github.com/MainQuestAI/Deck-Master/pull/323)）。
- **接入现有命令**：native 逐页还原接入 `deck run`、`deck build` 与 `deck export pptx`；候选须用非空 `--note` 明确采用，可包含 Tabler outline 图标与局部裁图（[#324](https://github.com/MainQuestAI/Deck-Master/pull/324)）。
- **只含图标的页面可以组装**：只含图标、没有位图的 native 页面子集可以 `deck build`。PptxGenJS 在没有其他媒体文件要读时，会把 SVG 写进 PNG 伴生部件；组装前只替换仍挂着 SVG 关系的那张伴生 PNG，其它非法图片仍由清洗拒绝。SVG 图标本身保留（[#328](https://github.com/MainQuestAI/Deck-Master/pull/328)，对应 #325）。
- **原图过期提示**：`deck build` 与 `deck export pptx` 列出原图依据已变的页：`stale_images`，以及 `warnings`（`code` 为 `stale_image`，`level` 为 `warning`）。不并入 `stale_pages`，不改变退出码或回读 status（[#328](https://github.com/MainQuestAI/Deck-Master/pull/328)，对应 #326）。
- **回读按对象扣减正文**：native 构建回读在每个文字对象内按占用位置扣减正文，不跨对象拼接。短 atom 只出现在更长的已绘制句子里时记 `missing_visible_atom`，仍只作为 findings，不让 assemble 失败退出，也不在构建时重跑 validate_plan（[#328](https://github.com/MainQuestAI/Deck-Master/pull/328)，对应 #327）。
- **重复 atom 与孤立列名警告**：`validate-plan` 对未声明的重复句子、以及小于正文且单独画出的列名给出警告（`repeated_atom`、`orphan_column_label`），不改变退出码或回读 status。方法说明补充了图标、裁图、有意重复和省略列名的登记方式（[#334](https://github.com/MainQuestAI/Deck-Master/pull/334)）。
- **图标 PNG 备用图**：native 组装用 rsvg-convert 按图标显示宽度渲染 SVG 的 PNG 备用图，替换 PptxGenJS 写入的红叉占位。某一张渲染失败时保留原占位，并在 findings 里记 `svg_png_fallback` warning，构建照常完成（[#339](https://github.com/MainQuestAI/Deck-Master/pull/339)）。
- **共用版式与空泛采用说明**：native 交回、采用和构建可以多给出警告，不改变退出码，也不把回读 status 从 pass 改成 fail。空白 `--note` 仍拒绝。警告不写入 native 包（[#340](https://github.com/MainQuestAI/Deck-Master/pull/340)）：
  - `canvas_not_original`：plan 画布与能打开的原图像素不同。
  - `shared_layout`：同一题头（标题框与第一条 shape）达到 3 页。
  - `note_unspecific`：非空 `--note` 去掉空白和标点后只剩确认用语。
  - native 的 task.md 在读到原图时写上像素尺寸，供 `plan.canvas_px` 使用；读失败就省略，不取消 run。

## 6. 已知未做与未验证

- **视觉人判仍由人做。** 本版没有把 `visual_review` / `desktop_editing` 改成自动通过，也不声称视觉验收已通过。
- **真实 Host / ImageGen**：本版不声称已通过。方法文档、合成测试与界面接线不能替代这些执行与判断。
- **PPTX → deck 导入仍未实现**：当前 `deck import` 读取的是已经存在的 `legacy-export.v1` 档案，不是 PPTX 文件。
- **内部 27 页还原验收，commit `b62ce271` 第 1 轮**：sim_v3 平均 0.674，命中 27/27，红叉占位 0。视觉由人判，不标通过。
- **其它既有边界**：UNC 路径不在本机路径清洗内，Markdown 导出不做 PPTX 正文那套凭据检查；字体检测不证明每个字形能正确渲染。详见 [1.1.1 已知限制](1.1.1.md#6-已知限制与未验证) 与 [首跑指南](../getting-started.md#known-limitations)。历史维护者观察保留原时点，不作为 1.1.3 的验收结论。
