# 1.0.0 release preparation — 2026-10-21

Status: source preparation, not a published release. Python version `1.0.0`
will map to `v1.0.0`. The final tag must name the verified, clean source used
for the release assets. No PyPI publication or user installation is implied.

## Changes and supported entry points

The release combines the existing rebuilt core with the RC5 method catalog,
bounded Host selection, content/evidence/method WebUI, recoverable handoffs,
image lease ownership fixes, support templates and documentation navigation.
The source and runtime version are both `1.0.0`.

Use the [first-run guide](../getting-started.md) for local installation,
CLI, loopback Workbench and upgrade. `make smoke`, `make test`, `make preview`
and `make package OUT=<new-directory>` wrap the current implementation.
Legacy release/RC Make targets fail with an explicit retirement message.
The broken Docker/Dev Container entry is retired, with rationale, alternatives
and historical source linked in [CONTRIBUTING](../../CONTRIBUTING.md#retired-container-entry-point).
No supported container runtime or network deployment is claimed.

## Validation and release gate

The preparation branch runs package/entry/resource checks, a fresh wheel/sdist
build, isolated installation and the installed synthetic offline browser/export
scenario. Results and exact build SHA are recorded in the PR handoff. A source
checkout result is never relabeled as an installed-wheel result.

Before publication:

1. Review and merge the version PR; verify the final main CI matrix, rendering,
   required browser and installed/offline groups.
2. Build from that clean final SHA with `tools/build_release.py`, verifying
   `source_dirty=false`, version, package metadata and canonical resource hashes.
3. Validate the final wheel in an isolated prefix and record actual CLI,
   Workbench and synthetic delivery checks; do not activate real user HOME.
4. Publish wheel, sdist, `release.json` and `SHA256SUMS` with accurate release
   notes after checking that neither `v1.0.0` nor its Release already exists.
5. Read back tag, release assets and digests, then record the milestone.

  quality inputs. They are not real customer production, independent model
  approval, professional human review or cross-platform certification.
- The earlier installed mobile-gallery scroll timeout remains unexplained;
  subsequent passing runs do not establish a root cause. Preserve the
  [diagnostic record](../reports/webui-content-methods/MOBILE-CI-DIAGNOSTIC.md).
  A recurrence on the release candidate requires investigation before release.
- Fontconfig/LibreOffice Chinese glyph limitations and unverified actual WPS
  editing remain disclosed in [known limitations](../getting-started.md#known-limitations).
  The earlier PR125 real Host task is evidence only for its stated SHA/scope.
- WebUI professional review and human acceptance remain NOT_RUN. No current
  tests upgrade these observations to PASS. Broad professional or desktop
  compatibility claims are outside the evidence reported here.
- Container build validation could not complete because Debian DNS resolution
  failed in the build environment. The unvalidated replacement was not shipped;
