# 问题清单与需求追踪

## 用户本轮明确要求

以下为本轮原话摘录，非模型推导：

> “简化Skill，不是说没有Skill，基本的流程还是要有的。”

> “内容怎么确定？逐字稿怎么确定？”

> “这个流程跟Skill的关系是什么？……对应的停顿点设计。”

> “生产这些逐字稿的过程和效果是什么？逐页稿子的过程效果是什么样子？说服的逻辑是什么？”

用户要求把这些问题、既往讨论、首轮诊断及相关记录整理成独立 Draft PR，交给其他模型详细诊断。这是当前范围。此处不向用户重新发起 PPT 内容访谈。

## 已确定的要求与尚未决定的选型

已确定：保留专业策划与协作；明示职责和可审查产出；已有有效决定可复用；用户可以只做某阶段；方向不明时不能直接当成已定；评估覆盖内容与使用效果；工程通过与用户认可分开；保留已有工作、资料与证据。

尚未决定：公开 Skill 数量与名称；Brief/Planner、Writer/Producer、Quality/Review 的拆分；逐字稿默认策略；样页数量；阶段确认粒度；各任务的评价标准与最低门槛；运行合同及实施包次序。本文候选值均可被审查改动。

当前 AGENTS.md 的“单一公开 Skill”是现状规则，本 PR 没有改写它；这是产品修订讨论所要评审的对象之一。未来若选择多入口，需要同时修改路由、安装、方法装载及验证，不能只加目录。
