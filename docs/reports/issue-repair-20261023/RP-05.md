# RP-05 — reuse verified SVG previews during assembly

Baseline: PR #184, `55adc97c5bb5f16ae7fcff7c33c43969fae9ce97`. Refs #152.

The old `produce` unconditionally required rsvg, prepared SVG raster inputs and
rendered every page, then discarded each PNG when `svg_preview` already existed.
The replacement verifies the preview object, page identity, exact SVG lineage
and stored byte digest before reuse. Only pages needing a preview require rsvg
and prepare/rasterize SVG inputs. PPT compilation, PDF/PNG rendering and native
readback remain unchanged. Explicit assembly still rejects missing/stale/corrupt
prerequisites; the existing page-preview recovery path now also validates a
retained slot before returning it. Immutable prior objects are not rewritten.
