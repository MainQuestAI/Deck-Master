## Diagnosis and implementation

On the exact baseline, the new unreviewed Content trial regression fails in
`change.commit`: the general production gate demands that the manuscript being
corrected first pass preproduction review. Page trials also carry a production
binding and generic repair methods, and both Skill reader protocols reject
Content on `kind=repair`.

Content-only, zero-call trial plans now bypass only the production review
prerequisite. Scope, authority, candidate budget and other gates are unchanged;
auto changes and visual production retain preproduction checks. New Page trial
Tasks bind `page_copy` and a single-page, page-copy-only write scope. Their
immutable method manifest uses Content page-writing methods. Content v1/v2
readers accept these Tasks; Design readers reject them. SVG repair stays Design.

Old Page-trial contracts report `basis_changed`. The existing formal method
reissue transaction preserves the original Task/manifest and creates a fresh
Content binding and Task identity, retaining explicit selected resources and
rejecting incompatible selections. It does not edit old objects in place.
The candidate Skill now documents this supported route.
