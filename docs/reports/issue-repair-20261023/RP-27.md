## Measurement method

[Raw measurements](RP-27-measurements.json) retain all 96 observations, CPU,
wall times, counts and result hashes. Before hashing, all 48 corresponding full
result values compared equal. This script performs no renderer/model call:

```sh
# Export baseline f586a7fe into /tmp/rp27-baseline first.
PYTHONPATH=/tmp/rp27-baseline/src:tests/rebuild python tools/benchmark_review_reuse.py --workload-root /tmp/rp27-workloads --out /tmp/rp27-before.json
PYTHONPATH=src:tests/rebuild python tools/benchmark_review_reuse.py --workload-root /tmp/rp27-workloads --out /tmp/rp27-after.json
```

The same immutable fixture tree is reused by separate baseline/candidate
processes. N=4/8/16 assembly fixtures have N pages, N committed history revisions,
fixed-length synthetic SVG and valid original/preview references. Synthetic
review records explicitly claim no actual visual/human approval. Closure fixtures
have N owners with the same finding ID, each with N historical replacements;
half remain unresolved. Strict-delivery fixtures use one actual synthetic PPTX
with notes and pure-reading projections; real zip bytes differ. That workload
measures `_facts` only, including both summary and strict professional policy,
not entire delivery latency or a successful professional sign-off.

Cold clears only the in-process snapshot header cache; warm runs one untimed
call before three observations. OS caches are not flushed. Time includes the
same instrumentation overhead. CPU values below are medians in milliseconds,
not p95. Baseline replacement-index counts equal finding_closed calls because
that implementation creates one unconditionally per call. Candidate counts
instrument the extracted function; page calls still perform all gate checks.
