## 根因与修改

登记资产已有真实不可变 Artifact/file，但旧 generation.prepared_input 仅复制 stage_request.references，允许的资产只以登记元数据进入提示词。实际运行 RP-17 版本 generation.py，在已经登记且选定合成 Logo 的同一项目上 references 为 []；新版本为固定原件 reference（`/tmp/rp19-before.txt`）。另发现无 SVG 时的保守“全部允许资产”失效回退会将未消费资产变化也用于 supersede 待制作任务；新准备改按实际冻结消费判断，旧请求规则保留。

新增 strict Page.visual_spec.design_overrides.selected_asset_ids：必须唯一并属于页面有效许可；新准备缺省不选图，许可不等于选用。strict asset-inputs.v1 合同记录原件 Artifact/file Ref、asset_id/kind/media_type/顺序。读取真实 PNG/JPEG/WebP 并校验格式与哈希；原始 provenance、external_use、版本不伪造。generation references 自动合并阶段参考与选中原件，精确重复去重；冻结时不得漏传。实际调用仍需原生事件匹配 references 和输出，未观察不当作消费成功。

新字段/准备提升 minimum_writer=asset-inputs.v1；旧 reader 不支持则拒绝。RP17 的 writer-floor 测试随单调提升更新为该精确值，模拟旧 reader 排除所有高于其支持边界的版本，未放宽断言。历史准备/任务/候选/采用原图按冻结 marker 选 resolver，不补策略或附件、不改旧字节。新消费只比较选定原件和实际字体元数据；原件字节、来源或权限改变失效，未选资产和纯登记时间变化隔离。固定候选 basis 保持历史编码。

## 格式支持矩阵（C6）

|格式|上传/登记与存储|选用与冻结|实际工具消费|本地成品核对|
|---|---|---|---|---|
|PNG/JPEG Logo、图片、icon|SUPPORTED：既有 import asset 服务存原件，保留来源；素材上传不自动登记|SUPPORTED：显式逐页选用、原件哈希/格式验证、冻结 reference|PENDING：已有原生收集协议，但本轮未调用 ImageGen，不声称图像模型使用成功|SUPPORTED（合成）：原件→本地 SVG→native PPTX，zip 媒体字节与冻结原件一致；非视觉认可|
|WebP 图片|SUPPORTED 登记原件|SUPPORTED 冻结并验证原件|PENDING 真实 ImageGen|UNSUPPORTED 当前 page_asset_paths 只物化 PNG/JPEG；不能宣称贯通重建成品|
|SVG Logo|SUPPORTED 登记原件|UNSUPPORTED 直接图像附件；明确拒绝，不隐式栅格化|NOT_RUN|当前同一路径不支持原件直接嵌入；需明确转换后独立登记|
|TTF/OTF 字体|SUPPORTED 原件登记；普通素材上传不接受字体扩展|元数据可绑定字体，UNSUPPORTED 作为 ImageGen 图片附件|字体注册不等于安装/模型精确字体消费|既有本地 renderer 使用 fc-match 已安装字体；本轮未安装字体，未证明注册字体自动嵌入|
|PPTX 模板|素材解析支持文档输入；asset kind 无 template|UNSUPPORTED 母版绑定；generation template_ref 保持 null|UNSUPPORTED 模板母版复用|正文抽取不称母版消费；NOT_RUN 模板成品验收|
|无资产自主设计|SUPPORTED|空 attachments，仍可准备/冻结|PENDING 本轮真实调用|本批不声称视觉成品|

实际 Runtime 接口：`deck-master import asset --project … --asset-id … --kind … --file … --external-use …`；页选择走已有 Page 编辑入口。未新增前端资产选择 UI。
