## Diagnosis and implementation

The exact baseline makes the current review summary `not_evaluated` immediately
when a zero-call Page candidate Task is dispatched. `evaluate_current` suspends
all pages with active Tasks, and the handoff checker independently rejects all
pending Host Tasks. Neither path distinguishes a candidate-only side branch.

Both readers now share `task_blocks_current_output`. A content trial with Host
reasoning cost, no call allowances, and no reported external calls does not
suspend current output. Other work still blocks, including original-image
trials and in-flight/unknown calls. Independent findings are still evaluated;
this change never closes findings or adopts a candidate. Queued required Tasks
are also included consistently in handoff pending facts.
