## Implemented boundary

`review original --project … --page-id … [--candidate-id …]` dispatches a
separate `original_image` Task and `visual_expression` review, including an
unadopted candidate. No SVG or preview is needed. The fixed packet binds the
actual Page, immutable original image and file bytes, owned generation recipe,
current consumed Page/Plan/design/asset requirements, and current request and
applicable decisions. PNG/JPEG/WebP bytes are decoded in their declared format.
Packet and Task reader expose the exact image path and fixed expectations.

Existing authenticated provider receipts bind packet, subjects, current Task,
execution, scope and result. No provider or no usable receipt returns
`needs_reviewer`; native text review remains explicitly unsupported for image
inspection. The Task additionally requires `original_expression_review.v1`.
New persisted facts require `original-review.v1` writer rank 18, after RP-19
`asset-inputs.v1` rank 17. Canonical schemas and their unique mirrors change
together; old runtimes refuse the new writer floor rather than reading a pass.

The reviewer must explicitly report observed node IDs, edge IDs/from/to/direction,
hierarchy and reading path. Runtime compares the reported graph with the fixed
Page graph, not with an invented pixel interpretation. A fixed A→B reported as
A→C is fail + open must_fix now; unknown or unresolved blocking findings cannot
pass. Runtime does not itself perform independent image interpretation.

Style expansion consumes `reference_status(..., use='expand')` and requires a
current authenticated original pass. Viewing, comparison and an explicit
`repair_reference` remain available with the issue warning. Relevant basis
changes invalidate results; unrelated page changes do not blanket-invalidate
the representative page. Candidate adoption preserves its applicable review.
New image pixels and a current closing review can fix an old original finding;
re-labeling unchanged pixels cannot. Original findings remain separate from
SVG/PPT conversion and final review stages, and historical records are retained.

under its new basis: the obsolete requirement does not permanently block a
fresh authenticated review. Unlocalized or unrecognized finding targets are
conservative; a generic document edit is not proof that their requirement was
withdrawn. Historical failure objects are not modified.
