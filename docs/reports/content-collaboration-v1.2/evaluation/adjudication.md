## 2. 分歧裁决

### 分歧 1：原型 locator 是否零错误

- **A**：P6 复核行"B 对应第 2 行"错误——情境 B 是"紧急且版本已知"，对应 P4 表格第 1 行。
- **B**："原型引用的全部 locator 逐条对照 fixture 原文，均准确"，并在自己的 P6 分析中同样写"情境 B 对应第 2 行（紧急+已知）"。
- **裁决**：以 P4 表格实际行序为事实源——第 1 行=紧急+版本已知，第 2 行=紧急+版本未知。情境 B（版本 V2.4 已知）对应**第 1 行**。A 正确；B 在交叉核对 fixture 行号时复读了原稿的同一处错误，恰好证明这类交叉引用必须回表核实而不能凭记忆。**修复**：原型 P6 复核行已改为"B 对应 P4 表格第 1 行（紧急且版本已知）"，并在其中标注本分歧。
- **影响**：答案内容本身（"写 V2.4，立即按紧急路径流转"）两评审均确认与 S2 第 5 行一致；缺陷仅在复核记录行。

### 分歧 2：口播时长余量的解释

- **A**：未测 P3/P4 大幅富余是否为"指表讲解"预留，要么预算错、要么 verbatim 偏薄。
- **B**：测得同一事实（P3/P4 各 +43/44 秒），判为"分配口径不一致，T08 计时前不能当排程依据"。
- **裁决**：无实质分歧，采纳 B 的处理方式——不回填解释性数字，把"预算为人工上限、逐字稿未计时"的既有声明保留，富余原因留待 T08 实际试讲定案。P1 的 -1 秒紧页已由 B 点名，归入同一 T08 计时项。

### 分歧 3：锚点数量是否充足

- **A**：指出三类各有缺口（受众/用途错配、跨页矛盾、合成声明删除）。
- **B**：指出四个更具体的缺口（答案泄漏、合成当真实、批准状态伪造、跨研究池化）。
- **裁决**：两集合互补而非冲突。B 的四项已按 AN-Q1-3/AN-Q1-4/AN-Q2-3/AN-Q3-3 增补；A 的"跨页矛盾"缺口不单独立锚——它已由 fixtures/q4b 的植入错误结构（P5 F0 + P1/P6 F1 联动）与 manifest V09 承接，属 Runtime 行为测试（T04），在 README 的 not_run 清单登记；"受众/用途错配"部分由 AN-Q1-4（用途限定）与原型第 6 节口播政策分支覆盖，完整的用途错配锚点在 T08 陌生实例中检验。
