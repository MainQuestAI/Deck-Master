## 用户可完成的操作

内容与来源页保留当前用途、受众、既定决定和材料。调整前展示实际差异；材料补充、替换、移除及用途说明使用核心输入事务，保存后明确待协调。已提取记录、打开原文、Host 已采用的影响判断分开；新输入尚未协调时此前判断明确标为旧依据。来源按固定版本与真实 locator 打开，精确位置缺失时只标材料级。

逐页稿可直接编辑标题、副标题及已有段落、列表、表格文字，保留结构与身份。保存前预览受影响页/未完任务/整稿输出，原图保留但说明依据需核对，不触发生图。鼠标按钮、拖动及 Alt+↑/↓ 支持页序草稿，焦点与选择跟随 page_id；移除确认后进入邻页，历史不删除。跨页改写、合并、拆分仅交接明确选页；合并/拆分新页可回溯只读旧页，旧意见不迁移。

章节、整合结论、页面目标和待确认事实在内容计划编辑区修改，不把正文塞进大纲。界面复用 DraftEditor/BusinessOperations：保存未知时持久保留原请求与 operation，核实不提交后写输入；冲突展示本机草稿与服务器新基准。项目级内容草稿增加严格 revision 匹配，避免输入变化但 ContentPlan ref 未变时旧草稿遮住新材料；原有意见/风格草稿规则不变。

- 主流程浏览器：15 项，包含段落/列表/表格文字与身份、刷新草稿、局部保存、键盘/鼠标重排、大纲正文分离、材料交接、移除邻页、响应丢失后的后写草稿保护及无横向溢出。
