# W08 跨页风格校准执行边界

基线为 W10 前端 PR #57 合并 `c17ba512db3efb4196b0e88dcab2d604eb23b053`，分支 `codex/workbench-w08-core`。W07-AC07 已有真实两页 auto/trial 交错、固定比较、采用与局部失效补证。先共享核心/契约/CLI 合并 main，再接前端；不改用户已确认的视觉方向。

新增不可变 StyleRecipe，固定参考页原图及版本、可读的请求来源与可信度、目标页内容/产物基准、简短要求和明确借用的维度。默认只借色板与文字层级，构图须单独选择；正文、标题、数字和论点始终来自目标页。建议与确认分开，历史 prompt 不存在就标未知，不自动拼接两页全文。可选精确 prompt 选段复用 W05 code-point 校验；Host 提取文本只能作为未确认建议。

proposal 为无派发的不可变预览；confirm 使用已有 operations/CAS 形成版本，修改产生新版本及 diff。冲突逐项显式取舍；旧版本与原始 prompt 不修改。首轮仅一页 trial；用户采用首张候选后，才能对配方中明确选中的其它页新建扩展计划，各页旧基准单独核查。复用 changes plan/commit、GenerationRequest、调用账及 Candidate，禁止新增执行器或调用账。

请求冻结保存配方对象引用及选定约束；任务与请求不能运行时读取最新配方。新写入边界保护旧 writer；未改页及参考页不变。自动化验证机制、并发/冲突/取消/晚到/额度与固定身份；真实图像试作、人工阅图评价、浏览器和用户验收分别记录，核心测试不代签效果改善。
