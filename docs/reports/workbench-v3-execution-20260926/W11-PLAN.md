# W11 固定版本与文件交付执行边界

基线：W09 前端 PR #62 合并 `314df380b2b8df9d7540132f99a190c1d0b2f047`，8 项 CI 全通过。先核心/CLI/HTTP/兼容文档合入 main，再接浏览器下载与历史恢复。

导出在开始时固定可达快照，读取不可变对象，允许后台继续提交。review 只含可阅读稿件、预览与缺项说明，不再携带原材料和内部项目；无 PPT 也可导出。delivery 复用所选快照 check_summary、输入对齐与专业政策，缺项以同一结构化错误定位。engineering 明确内部用途，只携带恢复所需历史/不可变对象与固定指针，不复制认证、运行锁、服务元文件或个人草稿。

每个导出使用固定 ID、用途、版本、manifest/hash；浏览器只按本项目导出 ID 与白名单文件下载。元数据清理产生副本，不改原对象；PNG 文本/EXIF/XMP、SVG 注释/metadata/不安全属性、PPT 属性/备注/关系单列检查。不识别的主动内容或私密位置明确拒绝，不删除正常可读正文与正常链接来凑通过。

历史恢复复用现有内容恢复规则，增加影响计划与原子回执。恢复新建版本，保留当前执行/调用/取消及 user_stop 事实，冲突保留双方。可编辑性、工程、专业与桌面证据分开；图片不冒充原生文字。
