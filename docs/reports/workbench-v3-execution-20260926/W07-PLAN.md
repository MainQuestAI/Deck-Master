# W07 核心执行边界

基线为 W06 前端 PR #52 合并提交 `fc800d500462c720963f3f9e60d87ce0f90aa838`。本卡先核心再前端；此文件记录实施选择，不表示功能已通过。

1. 复用 `changes plan/commit`，显式区分 `auto` 与 `trial`，阶段对应原图或 SVG 重建。固定参考图以已提交版本中的 Page/原图引用验证，再把实际文件引用和角色冻结到生成请求。Host 不得在请求冻结时遗漏计划指定的参考图或改换短要求。
2. Trial 任务沿用任务接手、调用与结果入口，只把经过现有内容/原图绑定/SVG 前置校验的产物保存为不可变 Candidate。任务/调用/候选管理版本可以前进，当前 Page/原图/SVG/预览/整稿引用不改变。保留取消/晚到和原 operation receipt 恢复。
3. Candidate 从已提交 Document/Task 引用可达，不创建独立 Document 分支、提交注册表或调度器。记录真实 request/attempt/result 引用、时间、生成依据和原采用目标。当前适用性按 Page、实际设计与输入语义及重建所需原图判断，不用全项目 revision 替代。
4. 集合采用共用只读预览与一次原子提交；单页是长度一集合。采用计划分别锁定候选、目标槽指针和当前 project CAS；先检查全部候选再切换指针。任何冲突都零采用，重新选择子集必须新计划、新 UUID。复用 W06 OperationCommit，不另建提交账。
5. Trial 与 auto 可并存。自动生产查找、任务复用和 `continue` 的阻塞判断排除 trial；实际全局未知调用或预算限制继续生效。固定参考图后来被替换时，旧引用仍是冻结输入，不能偷换成新图。
6. SVG 候选采用后走既有单页预览、逐页审图和整稿制作流程，不伪造独立单页 PPT。显式整稿阶段复用同一个 pipeline，拒绝缺依赖或未通过当前质量门禁；不提供绕过开关。
7. 新 Candidate 结构升级最低 writer 并防止后续意见、内容计划或历史恢复降级。历史恢复保留调用事实、候选与 terminal 任务；恢复同 page_id 不复活旧任务。
8. 核心测试覆盖集合冲突、三种不同基准、逆序/重复/取消返回、自动生产交错、旧 Host、固定历史参考图及指针/索引中断。共享核心合入后再实现比较 UI，随后真实参考图工具往返和真实 SVG 重建；mock 不关闭 W07-AC07。
