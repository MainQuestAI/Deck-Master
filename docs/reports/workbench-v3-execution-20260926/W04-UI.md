# W04：同层画廊与有界图片阅读

核心 [PR #47](https://github.com/MainQuestAI/Deck-Master/pull/47) 已合入 `e5e7892561400a06003971c8ad9239fb5e3b62af`，8 项 CI 全绿。前端实现提交 `33c99bed12cd9c352a1429955fe798c1f9646b2d`，仍使用可选 `/v2/` 入口。当前工程验证不等于整卡用户验收。

画廊支持 2/3/4 列联系表、连续阅读及 2–4 页并排，原图/SVG/PPT 按固定版本读取。SVG 在安全图片上下文中绘制为位图，不注入 SVG DOM；PPT 只显示该页已记录的 PPT 预览。缺失层保持占位，不能用其它层补位，也不把“可看”说成质量通过。

章节、缺失、失效、个人意见、个人参考筛选不会清空选页，界面说明筛选外选中数。个人意见当前指同版本已保存的个人草稿，尚未包含 W06 的结构化批量意见。个人参考锁定选择时的原图与版本，可单独移除，不写入 Recipe。历史比较在新版本出现后保持旧基准，只有明确切换才读当前。

连续阅读保存页身份和页内位置；方向键切换焦点、Enter 进详情、Escape 返回原处。比较默认完整适配画布，可切换同步/独立缩放。两页与四页比较均有实际浏览器证据。1280/1440 下标题、层、文字状态及操作保持可辨。

所有画廊、比较和单页图片共用 6 个网络位、2 个解码位。LRU 键包含逻辑项目身份、内容 hash 和派生版本；含可见图片在内最多 60 张缩略图、4 张大图。离屏 DOM 被移除，淘汰的 ImageBitmap 调用 close，临时 SVG Blob URL 解码后释放。已经开始的本地响应读取完后丢弃过期结果，不会贴回旧视图。图片失败保留页面身份、层、选页与重试入口。

个人状态采用条件保存。未知 ACK 保留原请求，核实后才保存后续选择；两个窗口冲突时可比较并明确选择使用哪份。离线保留已读画面。读取另一窗口时的像素舍入不触发保存，避免无意争抢 ETag。

## 可运行验证

```sh
PYTHONPATH=src python examples/workbench/w04_gallery.py --out /tmp/w04-gallery
PYTHONPATH=src python examples/workbench/w03_browser_edges.py --out /tmp/w04-edge-regression
```

[脚本](../../../examples/workbench/w04_gallery.py)使用真实本地服务和真实 Chromium。输出目录必须新建；原始 trace 可能含本地会话头，只保留在本机，不提交仓库。[18 项检查与原始采样](w04/browser/checks.json)保存源码 commit、16 个 UI 资源 hash、硬件、视口、fixture manifest、对象规模及并发/缓存计数。

测试中修复了两个实际交互缺陷：重绘恢复旧焦点覆盖方向键目标；浏览器默认滚动锚定与虚拟化互相推动、导致连续向下跳页。新增跨多个动画帧的检查，不只看点击后的瞬时状态。另修复了恢复锚点触发无意条件写入的问题。早期故障注入脚本的动态定位也已改为稳定 page_id。

运行环境：macOS 27.0、Apple M5 Pro / Mac17,9、64 GiB、Python 3.12.12、Chromium 149.0.7827.55。30 页热首屏在两个视口各采 3 次，包含导航、JSON 读取/解析、可见缩略图完成及真实选页响应；全部 ≤2 秒。准确时长见原始采样，冷派生单独列出，没有排除 JSON 或放宽阈值。

固定源码提交的 1280 采样为 0.180/0.179/0.175 秒，1440 为 0.182/0.176/0.178 秒；冷派生首次为 0.295 秒。W03 主流程 15 项、边界 13 项浏览器回归通过；边界脚本按新图片画布和明确的总览入口定位，仍验证真实旧核心、配额失败及 SVG 安全。核心/HTTP 相关 52 项通过，JS 语法、Ruff、diff 检查通过。源资源 hash 已逐个与源码提交核对。

80 页连续缓存遍历用于验证淘汰与释放，不是完整压力模型。实测网络/解码峰值 6/2，缩略图/大图峰值 60/4；淘汰后关闭位图，SVG 临时 Object URL 最终为 0。来源全部是明确标注的合成图片、SVG 和 PPT 预览；没有模型调用，也没有实际 PPT 渲染或专业通过记录。
