# 前端动作与后端能力矩阵

本轮核验截至主线 d1c7c4；分类是实现性质，不是进度百分比。既有后端可复用也不表示 v3 前端已接线。

“前端为主”仍需真实浏览器与性能验证；“补服务/接口”复用现有业务对象；“扩展核心机制”需要新增业务语义；“条件能力”明确数据/工具/效果限制。原型中的模拟接手、模拟返回和重置样本按钮仅用于演示，不是正式产品功能。
