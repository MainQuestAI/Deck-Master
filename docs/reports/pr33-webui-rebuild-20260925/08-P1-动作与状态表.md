# 08 · 方案工作台动作与状态表

版本：v1.1，2026-09-26。B1-1 实施输入；本文定义目标行为，不表示接口已实现。

依据：[03 方案](03-Deck-Master方案工作台重构方案-v1.0.md)、[04 的 G0](04-B路任务执行单.md#6-决策记录)、[05 浏览器证据](05-P0-旧UI浏览器基线.md)、[07 接口草案](07-P0-共享接口草案.md)。用户本轮已确认完整工作台分阶段交付、稿件/修改双工作面、可外发审阅文件与独立工程包。G1 原型试走、G2 真实往返、G5 默认切换仍须实际完成，不能用范围确认代签。

## 1. 工作面与首屏

第一用户是使用 Codex 持续制作方案的个人负责人。工作台回答：当前稿是什么、我要改哪里、谁接手了、返回了什么、能取得哪个版本的文件。

- **稿件**：首次进入整稿概览；支持连续正文阅读、业务标题查找和单页阅读。没有预览时展示真实正文摘要，不做空白幻灯片缩略图。
- **修改**：按用户修改组织意见、页面范围、交接、真实进展和固定结果比较。一项修改的多个制作任务合在同一条工作记录下。
- **上下文面板**：任务与材料、版本、导出。制作详情与诊断是次级入口，不常驻审批栏。
- 再次进入恢复页面、未提交输入、缩放与固定比较对象。后台结果不抢焦点、不切页。
- 当前 PPT 预览优先，其次是明确标注的制作预览，再次是完整正文。旧成品显示来源版本和“正文已更新，成品待更新”。原图、SVG、PPT 的专业对照放在制作详情。

## 3. 用户动作表

所有写入动作在 300ms 内给出本地反馈（按钮忙碌、文字提示、输入保留）；这不是服务端完成时间承诺。失败时不清除输入。表中接口尚未交付时，正式界面隐藏相关入口；原型统一标“样本”。

| 打开稿件 | 项目可读 | E1 | 阅读骨架 | 首次概览/再次恢复位置 | 连接中断，保留最后同步内容 | P2 |

## 4. 状态映射：内部事实与用户表达分栏

此表是显示规则，不新增运行时状态机。状态只从持久化结果、现有检查或明确本地输入产生。手动模式没有送达回执，因此不提供“已送达”状态。

| 内部事实组合 | 用户文案 | 视觉标记 | 下一步 |
|---|---|---|---|
| local dirty | 尚未保存 | 中性点+文字 | 保存或撤销草稿 |
| 写入未得到确定回执 | 尚未确认是否保存成功 | 琥珀提示 | 按原操作身份核实或重试 |
| queued | 修改要求已保存，等待处理 | 中性文字 | 查看详情或取消 |
| awaiting_host，无 execution_ref | 等待 Codex 接手 | 琥珀点+文字 | 复制交接文本或打开预填对话 |
| 仅 clipboard 成功/深链接触发 | 已复制，请粘贴发送 / 请在 Codex 中发送 | 行内提示 | 继续等待真实接手，不改变执行状态 |
| running，有接手记录且未超时 | Codex 正在处理相关页面 | 进展标记+领取时间 | 看旧稿、查看进展或取消 |
| running，领取已过 30 分钟 | 长时间未完成，可取消或重新交接 | 琥珀提示 | 显式取消或重新交接；不自动接管 |
| 当前正文变化，画面仍属旧版 | 正文已保存，成品待更新 | 画面顶部旧版标签 | 看新正文/旧画面，交接继续制作 |
| completed，仅有新正文 | 正文已更新，画面待制作 | 文字状态 | 阅读正文，继续必要制作 |
| completed，只有制作预览 | 制作结果已返回，PPT 尚待更新 | 制作预览标签 | 比较制作结果、继续制作 |
| 当前结果已采用，缺适用审阅 | 新结果待复核 | 琥珀文字 | 看新结果和待处理项 |
| 当前产物有适用复核，且前后结果已关联 | 有新结果，可比较 | 绿色点+文字 | 比较、再改；整稿能否交付另看共享检查 |
| cancelled | 本次修改已取消 | 中性文字 | 看旧结果、重新提出修改 |
| superseded | 要求已变化，本次修改不再采用 | 中性提示 | 查看当前要求，重新交接 |
| failed，含真实原因 | 本次处理失败：具体原因 | 红色文字 | 保留旧结果，按失败步骤恢复 |
| 409，基准与服务端有实质冲突 | 这处内容已有更新，你的输入已保留 | 冲突面板 | 对照原稿、当前稿和本地输入后另存 |
| 页面已移除 | 此页已从当前稿移除 | 中性提示 | 返回整稿或只读历史；旧选区不迁移 |
| 取消/失效后的 late result | 旧任务的返回结果未采用 | 行内说明 | 查看当前稿，不恢复旧页 |
| 网络不可达 | 连接中断，当前显示上次同步内容 | 顶部细条+时间 | 保留输入，重连后核对当前版本 |
| repair_no_progress / 未关闭 finding | 这个问题尚未解决 | 具体问题与位置 | 查看差异和待补说明，继续修订 |
| 批量中部分结果完成 | 部分页面有新结果，其余仍在处理 | 分页进展 | 分别比较、重试失败项 |
| 共享 check_summary 判定可交付 | 当前版本可导出交付文件 | 导出面板绿色文字 | 固定该版本导出 |

### 同页多状态的优先级

正文保存、画面版本、修改进展分别呈现，不挤成一个全局“完成”。冲突/连接中断优先显示在输入附近；画面上的旧版说明始终保留；下一步主动作随当前用户意图变化。示例：正文区“已保存”，画面顶端“修改前成品”，修改记录“等待 Codex 接手”。任何一项都不代替其他事实，也不阻止继续读旧稿。

## 5. 异常与恢复

| 情况 | 保留的数据 | 恢复顺序 |
|---|---|---|
| 服务断开 | 最后同步稿、页面位置、草稿、选区基准、比较双方 | 显示断开；恢复后先读当前事实；只有真正冲突才要求选择 |
| 保存结果未知 | 原操作 ID、完整提交体、本地输入 | 查询对应修改；尚未确定则用相同 ID 和相同内容重放；不能换 ID 盲重提 |
| 版本冲突 | 基准正文、服务端正文、本地草稿 | 展示三方差异；无关页变化按核心规则处理；实质冲突由用户决定，另存用新操作 ID |
| 执行失败 | 原请求、失败步骤、已有产物 | 只重试相关步骤；请求仍可追溯，不重新初始化方案 |
| 取消与晚到 | 已有产物、请求和真实调用记录 | 等取消回执；回执成功后拒绝旧结果；外部调用仍可能结束，不声称立刻停止 |
| 并行修改 | 每个请求的范围、基准、选区 | 同页同批合并；已接手的任务内容不改写；跨页依核心冲突判断，不按提交先后覆盖 |
| 本地持久化不可用 | 内存里的未提交输入 | 明确提示刷新可能丢失，提供复制输入；不虚报“草稿已保留” |

已完成后的相同意见：用历史请求显示“这条要求已处理过”；用户明确再次提出时创建新操作。该提示只提醒，不用文本相似度阻断合法的新修改。

## 6. 轮询、草稿与固定比较

- 活动工作每 3 秒读取 I4；闲置每 15 秒；单请求在途时不并发发下一次。隐藏标签页暂停，聚焦立即核对。失败按 3/6/12/24/30 秒退避，成功后恢复对应间隔。
- 摘要变化后才读完整视图。轮询不调用 `continue`、不创建任务、不运行模型。超时提示可由已投影的领取时间解释，但任务迁移必须经服务端动作。
- 草稿按项目身份、稳定页面 ID、编辑类型、基准内容版本保存。页面顺序变化不改变草稿归属；基准产物变化使旧选区失效，意见文本仍保留。
- 更新 DOM 时保留焦点、选区内输入、页面、缩放与滚动位置；有新结果只提示。
- 比较双方为明确的版本和产物引用；结果再次到达不替换当前比较。点“查看最新结果”才换比较对象。
- 保存成功只清除这次提交对应的草稿；提交期间用户又输入的新内容继续保留。

## 7. 术语和交接文字

| 内部名称（只允许诊断区） | 普通用户界面 |
|---|---|
| run / project_id | 方案 / 方案名称 |
| page_id / scope_pages | 页面标题 / 涉及页面 |
| revision / hash / sha256 | 版本时间与变更摘要；摘要缺失则显示真实修改范围 |
| awaiting_host / execution_ref | 等待 Codex 接手 / 接手记录（不展示内部标识全文） |
| result_refs / artifact / slot | 本次结果 / 画面 / 正文 |
| finding / must_fix | 具体问题 / 需要修正 |
| repair / reconstruct / review | 修改 / 制作 / 复核 |

交接步骤：保存意见 → 选中本轮修改 → 复制文本 → 粘贴到已有 Codex 会话并发送 → 回工作台看真实进展。次入口打开新对话并预填，仍需发送。文本由服务端生成，包含准确项目与所选任务，不含会话 token。项目路径和执行命令只出现在明确的交接/诊断内容，不进入稿件、缩略图或外发文件。

|---|---|
| U01/U02/U14 | 正文阶段可读；标题找页；首次概览；再次恢复位置；两种桌面尺寸和键盘可操作 |
| U03 | 正文/意见不串页，刷新保留；旧成品可看且标旧；保存中新增输入不丢 |
| U04/U05 | 选区绑定原画面；同页多意见合并；领取前不显示处理中；前后结果固定；两轮再改 |
| U06/U07 | 页面身份、来源与意见归属；移除页不因晚到结果回来；合并拆分不假迁移区域 |
| U08 | 输入事实保留；材料上传、读取和影响判断区分；真实影响范围 |
| U09/U10/U11 | 双击、超时、冲突、断线、取消、失败与重新交接；保留旧结果和输入 |
| U12/U13 | 历史先看后恢复；导出固定版本；外发审阅与工程材料分离 |
| U15 | 正常安装前端资源完整、离线可读；真实宿主另行验证 |

本文为交互规格。B1-2 用可见样本验证操作理解；P2 接真实接口；B2-4 与 B5-2 分别记录源码环境和正常安装下的真实 Codex 往返。任何模拟按钮不得出现在正式工作台。
