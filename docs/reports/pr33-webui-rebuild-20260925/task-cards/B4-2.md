## 目标

用户能只读地查看任一历史版本、与当前版本比较，并恢复到该版本（恢复会生成新 revision，不改写历史）（U12）。

## 已知事实（B0-3 F4）

- `/api/history` 只返回元数据；`project_view(revision=)` 已存在，但没有路由暴露。
- `/api/restore` 基于 `operation_id` 幂等，恢复会生成新 revision；**任务和调用事实不会回滚**。

## 接口部分（S 类 PR）

- [ ] 1. `GET /api/view?revision=<id>` 或 `GET /api/history/<id>/view`：返回该版本的只读投影（复用 `project_view(revision=)`）。revision 不存在时返回 404。
- [ ] 2. 测试：读取历史版本的页面和产物 sha 与当时一致；不存在的 id 返回 404；该路由不能写入。
- [ ] 3. 合入 `main` 后 rebase。

## 前端部分

- [ ] 4. 历史列表：时间、来源（用户修改 / Codex 任务 / 恢复 / 整稿操作），对应到 task（如有）。
- [ ] 5. 只读查看：进入历史版本时显示明显的“历史版本 · 只读”标识，禁用所有写操作。
- [ ] 6. 比较：选择两个版本（默认历史 vs 当前），按页显示哪些页变化了，页内并排显示画面。
- [ ] 7. 恢复：确认对话中说明“会生成一个新版本，之后的版本不会被删除；已完成的 Codex 任务记录不会撤回”。恢复后回到当前版本视图。
- [ ] 8. 测试：只读模式下写按钮不可用、写请求不会发出；比较时变化页标记正确；恢复后 `history list` 多一条记录、之前的版本仍在；双击恢复只生成一个 revision。

## 可改范围 / 禁止

- 接口部分只改 `web.py`（可能涉及 `view.py`）和测试；前端部分只改 `static/v2/` 和测试。
- **禁止**：恢复时删除或改写历史 revision；在前端中宣称“任务已回滚”。
