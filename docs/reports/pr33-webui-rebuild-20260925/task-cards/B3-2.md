## 目标

用户在工作台中补充材料、修改受众或用途后，能看到哪些页会受影响，并决定把哪些页交给 Codex 更新（U08）。

## 可改范围 / 禁止

- **可改**：`resources/static/v2/`；前端测试。
- **禁止**：改后端；前端自行推断影响范围（必须以接口返回为准）；在 UI 中显示材料的原文全文（只显示文件名、大小、登记时间）。
- **数据安全**：测试和截图只能用虚构材料；不能用客户资料做测试夹具。

## 实施步骤

- [ ] 1. “稿件目标”面板：显示并编辑 brief / 受众 / 用途，保存时带 `base_revision`。
- [ ] 2. “材料”面板：已登记材料列表；添加材料（按 S3-2 的方式：上传或登记路径）。
- [ ] 3. 保存后显示影响清单：受影响页面 + 原因；用户勾选 → 生成更新任务（单页或跨页）。
- [ ] 4. A2 未提供影响分析时，显示“无法自动判断影响范围，请手动选择要更新的页面”，**不猜测**。
- [ ] 5. 测试：改受众 → 影响清单 → 勾选两页 → 生成任务；材料上传失败的提示；409 时保留编辑内容。
