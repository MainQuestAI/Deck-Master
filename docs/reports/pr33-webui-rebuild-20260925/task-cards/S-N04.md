## 设计要求（先写半页设计，经验收人确认后再实现）

1. 旧产物怎么处理：保留并标记为过期（`stale`，带 `reason` 和触发的 revision），还是作废但在读模型里给出明确的 `notice` 和 `reason`。**推荐前者**：用户仍能下载旧版，并看到“已过期，因为……”。
2. 过期状态下，`export --purpose delivery` 和 `handoff-check` 的行为：必须拒绝，或者要求重新生成。不能把过期产物当作当前产物交付。
3. 哪些操作只影响单页产物、哪些影响整套：改一页正文时，不能把与这一页无关的产物也作废（如果技术上做不到，必须在设计里说明原因）。
4. `deck_view.v1` 新增的字段：只加可选字段，写清楚字段名。

## 可改范围 / 禁止

- **可改**：`editing.py`、`tasks.py`、`service.py` 中上述位置及必要的辅助函数；`view.py` 只做字段投影（共享接口，本卡作为 S 卡合入 main）；`tests/rebuild/` 新增测试。
