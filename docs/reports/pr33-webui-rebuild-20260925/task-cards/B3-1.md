## 目标

在整稿概览中支持重排、移除、合并、拆分和跨页改写，操作结果可见、可撤销（U06、U07）。

## 可改范围 / 禁止

- **可改**：`resources/static/v2/`；`tests/rebuild/test_workbench_v2_*.py`。
- **禁止**：改后端；前端本地伪造操作结果（必须以接口返回的新 revision 为准）；在没有二次确认的情况下执行移除或合并。

## 实施步骤

- [ ] 1. **重排**：在概览中拖拽，同时提供键盘方式（选中页面后 Alt+↑/↓），满足 U14。放下后调用 reorder，成功后按新 revision 重绘；失败时回到原顺序并提示。
- [ ] 2. **移除**：确认对话中写明“可以从历史恢复”；成功后提供“撤销”入口（调用 restore 回到操作前的 revision）。
- [ ] 3. **合并 / 拆分**：选择多页 → 合并；单页 → 拆分（按 S3-1 设计说明的输入方式）。完成后，新页显示来源（`derived_from`），以及“需要重新制作”的状态和下一步（交给 Codex）。
- [ ] 4. **跨页改写**：多选页面 → 写一条意见 → 一个作用于多页的任务；请求卡片中显示覆盖的页面范围。
- [ ] 5. 页面有进行中任务时，按 S3-1 的设计规则禁用操作，或提示任务将被取代。
- [ ] 6. 测试：四种操作 + 撤销；键盘重排；有进行中任务时的限制；操作后刷新，顺序与来源正确；拖拽过程中 revision 已被他人更新时正确处理 409（显示“稿件已更新，请重试”，不覆盖他人修改）。
