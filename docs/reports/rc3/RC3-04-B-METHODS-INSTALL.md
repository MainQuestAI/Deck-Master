## Implemented behavior

Four public Skills declare use/do-not-use, allowed artifacts, completion and
next responsibility. Master coordinates one Runtime and scope; Content has
plan_only/write_only/speech_only/content_full exits; Design consumes fixed
manuscript/relationship/scope and returns a scheme or bounded candidate; Review
uses strict external reporting without production or source writes. Switching
Skill names does not create independent reviewer identity.

The shared editable method source remains `skills/deck-master/references`.
Other Skills have entry metadata only. `read_task_methods` and task-bound
`read_skill_methods` consume the **actual workorder.method_resources list**,
with canonical-root/path/id/SHA validation, rather than assuming a fixed method
count or adding calibration to all roles. Missing declared calibration remains
a hard failure. Supplemental entry routing is separate from dispatched methods.
No experimental product profile or JSON switch was added. This permits the
later isolated four-method/old-loader versus five-method comparison without
changing common non-content or four-Skill foundations.

`read_skill_methods` accepts named/natural/master/recovery entry modes, returns
actual method bytes and the pure shared completion projection, and never
creates/claims/dispatches a task or grants scope. Master/recovery require the
existing project. Task kinds are checked against the requested responsibility;
natural routing is a responsibility suggestion, never authority. Returning
bytes is explicitly distinct from Host application.

The shared physical-units method is dispatched with blueprint/reconstruct,
repair, page/final review and applicable design/production workorders. It covers
current logical/physical canvas, contain k, SVGpx*k*0.75pt, actual p:sldSz,
explicit-role visible-run effective fonts, unverifiable roles/inheritance and
SVG/native-rendered padding. No converter constant, frozen prompt or external
font wrapper changed. Historical Desktop language no longer claims this round's
actual human desktop acceptance.
