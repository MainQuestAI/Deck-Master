## Owner core interfaces

- `service.create` preserves existing arguments and adds `request_input=None`, `adapter_context=None`. Omitted format creates v3/rc3-entry.v1 with exactly one collaboration region and real instruction source; no production grant. Default pending task is compose.v2 framing. `request_input` uses existing start_request input; it is not a trusted context.
- `service.import_draft` preserves draft_path/draft_payload and adds `base_revision=None, operation_id=None, instruction_evidence=None, request_input=None, preserve_mainline=True, adapter_context=None`. Existing project writes require current CAS; new project import is initialized privately. Pages and real source+imported_mapping are adopted atomically. No legacy compose route. CLI create --draft/import-draft/HTTP use this route.
- `collaboration.start_request` remains the single start/replace service. Optional input.variant_transition is `{kind:next_variant|edit_variant, source:{revision_id,export_id?}}`. Explicit source and current control are resolved atomically; next starts fresh Plan/Page/output with shared fixed Narrative; edit activates the selected historical content context under current control and exact new scope. Same source/op retries do not refresh credit. Current closed requests may start the second declared variant.
- `collaboration.pause_request/resume_request` gain optional `request_id=None` checked inside the transaction. Revoke uses its existing authorization_id. Migration apply accepts optional `instruction_evidence=None, request_input=None, adapter_context=None`, never implies business approval.
- `content_production.completion_status(store,document)` is pure and returns `state,request_id,intent,content_intent,artifact_revision_id,effective_scope,outputs,checks,missing,responsible_role,next_action`. States: in_progress/awaiting_decision/needs_reviewer/needs_recovery/completed. service responses include `completion`; completed content-only does not dispatch production. B/C consume this projection, not project-wide work_complete.
- `review_import.describe_bindings(project, *,external_report,artifact_revision=None)` is pure. `review_import.import_report(project, *,external_report,source_bindings,evidence,base_revision,operation_id,artifact_revision=None,adapter_context=None)` is Owner's sole Store/CAS import. external_report=`{report,report_sha256}`; source bindings use source_uri/source_sha256/target_ref/optional target_file_sha256. Historical subject records are appended under current control, never upgraded to human or independent by JSON.
- `delivery_eligibility.describe(project, *,revision=None,file_path=None,notes_policy=None)` supplies one selected actual output/current-control judgement to export/handoff/readiness/Studio. Result includes actual selected projection file hash/notes policy, engineering/collaboration/professional status, reason codes and both revisions. file_path, if provided, must match the selected exact output/projection; no arbitrary claimed manifest.
