# OpenDesign 正式工作台

Studio 是正式默认工作台，按当前 OpenDesign 方案迁移布局、对象选择和操作分组。运行 `deck-master workbench` 打开项目列表；已有项目用 `deck-master workbench --project <绝对路径>`。`deck-master view --open` 和服务根路径同样进入新版。需要兼容旧界面时可显式指定 `--ui v2`。

`/studio/` 与项目 API 同源，复用 `/v2/app.js` 中的正式对象、请求、候选和草稿机制；不加载原型示例对象，也没有浏览器直接执行模型的旁路。制作动作保存交接后仍由支持相应能力的 Host 执行，结果返回后通过界面比较和采用。

正式界面包括：

- 总览明确的四类选页动作、15 页分页矩阵、跨分页选择，以及紧凑的同步提示、重试和详情。
- 风格工作区四个阶段按钮；参考与目标使用卡片选择，规范先读后改，已确认规范搜索和分页。
- 内容工作区按概览、逐页编辑、内容计划和工作笔记切换；章节与材料优先显示。精确选段编辑进入原文/改文核对，预览与确认使用同一真实事务。
- 单页画布上方的工具入口、固定操作区、笔记/恢复切换和就近图标入口；图标处理方式与样例使用可见选择卡片。缺少原图或 SVG 时，可带当前页与固定版本进入制作配置，核对后才交接。
- 画廊制作选择与比较选择分开约束；制作可跨筛选保留范围，进入总览后受限页明确列出，不自动缩减范围。
- 候选按修改组选择和跨页批选；同页多候选保留用户选择。比较图之后紧接决定动作，依据与参考在后，不以浮动栏遮住作品。
- 浏览器真实材料文件接收与原 UUID 恢复，输入确认前不改项目内容。
- 任务按对象、状态和动作排列；版本区分选择、阅读和当前版本；文件区直接下载固定版本的 PPT 和 ZIP。
- 清理备份下载、逐字段恢复预览和确认；同名后写草稿另存，已有阅读设置保留。

材料上传使用 `material_uploads.v1` 能力标记。上传回执只是暂存；原文件的提取与 Source 登记仍由 `/api/content/inputs` 的用户确认完成。旧核心没有该能力时保留原完整路径入口。未知结果沿同一上传 UUID 核实，不自动换身份重传。

窄屏画廊把筛选与阅读偏好收进明确的设置按钮，空选时不铺开制作参数。图标目录失败显示独立的重试入口，切换处理方式不会隐藏恢复路径。

构建 wheel 时同时打包 `resources/static/studio/*` 与现有 v2 资源。独立安装须从中性目录、移除源码 PYTHONPATH 验证模块路径和 BUILD_ID；源码预览不能代替已安装包的验收。

本次完整对账、真实 Host 工具回执及下载文件核验位于工作树 `output/opendesign-completion/`；生成项目和二进制产物不纳入源码提交。原型交付目录保留 98 组 CSV 和后续补齐报告。
