## 按钮与状态流转核对

核对十个场景的按钮与处理分支，补齐状态前置条件及确认弹窗有效性：

| 场景 | 核对结果与修复 |
| --- | --- |
| 正文 | 输入未改变时不追加版本；空内容仍保留输入并提示 |
| 保存结果未知 | 只允许 unknown→核实；not_committed→重放；committed/replayed→独立后写草稿，重复操作不追加记录 |
| 内容冲突 | 新草稿只建立一次，重复动作不覆盖后续编辑 |
| 批量返回 | 采用与保留互斥；核实后才能取消；取消后才能建立新交接；重复重试不追加同一请求 |
| 整稿重组 | 请求保存后锁定移动/删除；无请求不返回候选；候选只返回一次；采用须有来源页和有效确认 |
| 历史恢复 | 先查看再比较，之后才允许恢复；原调用记录保持 |
| 框选标注 | 已保存意见不重复追加；编辑意见或选区后允许再保存 |
| 连接状态 | 检查中禁用再次开始，重复动作不追加记录 |
| 导出清单 | 未选择不能核对；改选后清单恢复待核对，未生成真实文件 |
| 加载态 | 处理中不能重复开始；只接收当前处理的模拟完成/失败 |

取消或关闭确认弹窗后，其确认动作失效；移除、重组、恢复、任务取消与重置不能跳过对应确认。

新增行为回归覆盖非法/重复迁移、关闭弹窗后拒绝确认、页序锁定、固定来源关系、保留后拒绝采用、取消后新交接、后写草稿与历史事实不被覆盖。十场景及工作台回归、token 一致性均通过。证据为最小 DOM 与直接处理函数回归，不代表真实浏览器点击验收或真实服务状态验证。

## 主工作台键盘与焦点审查

方向键只在非交互内容上翻页；输入框、选择器、按钮、链接、summary、可编辑内容和组合快捷键不被拦截。翻页时阻止默认横向滚动；弹窗打开时 Escape 不再改变背景框选模式。弹窗双向 Tab 循环保持。
