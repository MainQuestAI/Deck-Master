# Deck Master 产品 UI 语言规范

## 适用范围

主工作台使用正式产品文案。状态规范页是独立的交互参考，不进入产品导航。当前实现仍为本机工作区，生成、导出和云端同步尚未连接；文案调整不改变这一能力边界。

## 信息层级

- 页面标题：直接命名工作对象，如「项目」「制作总览」「整稿画廊」「任务与交付」。
- 页面说明：说明当前可完成的工作，最多两句，不介绍系统实现。
- 状态：表达已发生的事实，不把复制、保存、提交、处理和完成混为一谈。
- 按钮：使用「动词 + 对象」，如「创建项目」「保存草稿」「采用候选」「取消任务」。
- 辅助说明：只保留影响用户判断的后果、限制与下一步。

## 统一术语

| 使用 | 不使用 | 含义 |
| --- | --- | --- |
| 项目 | 原型项目、模拟新建 | 用户管理的一份方案 |
| 示例项目 | 合成演示项目 | 预置内容，不是真实客户资料 |
| 制作工具 | Host | 执行生成工作的外部工具 |
| 任务 | 模拟请求、样本任务 | 已保存的工作要求 |
| 候选 | 样本候选 | 尚待用户确认的结果 |
| 当前版本 | current、currentVersionId | 正在使用的版本 |
| 制作要求 | 交接文本 | 提交给制作工具的内容 |
| 本机工作区 | 离线设计原型 | 数据保存范围 |

Codex 仅在确实需要用户前往该工具执行时出现。SVG、PPT、版本号等对产物判断有用的技术名称保留。

## 状态与操作

| 事实 | 状态文案 | 下一步 |
| --- | --- | --- |
| 要求已保存，尚未发送 | 待提交 | 复制制作要求 |
| 仅复制了文本 | 已复制，尚未开始 | 在制作工具中发送 |
| 已取得执行记录 | 处理中 | 查看任务或取消 |
| 结果返回但未采用 | 待确认 | 比较候选 |
| 用户采用结果 | 已采用 · 待检查 | 检查相关页面 |
| 执行失败 | 失败 | 调整要求后重试 |
| 请求已取消 | 已取消 | 查看记录 |
| 上游内容已更新 | 旧版 · 待更新 | 更新相关产物 |

现有示例执行记录必须标明示例，不可用「处理中」暗示真实服务已连接。

## 能力与错误说明

连接信息集中在「连接状态」；涉及文件上传、导出或跨设备保存时，在操作处保留必要限制。错误消息依次说明发生了什么、内容是否保留、可采取的动作。例如：「保存失败，输入仍保留。请重试或复制内容。」

破坏性动作说明删除范围和能否撤销。清除本机数据必须二次确认。采用候选必须保持版本比较与影响说明。

## 界面边界

主界面不出现模拟接手、模拟返回、模拟失败等测试控件。不自动推进任务，也不伪造生成成功。状态规范页可保留明确标注的模拟操作，用于检查异常分支。

## 视觉与图标

沿用 OpenAI token、无衬线产品字体、黑色主按钮与浅灰表面。图标沿用共享的 24 单位 SVG、1.75 线宽和圆角端点。状态必须同时有文字，不依靠颜色传递事实。

## 文案验收

检查导航、标题、按钮、输入提示、状态、空态、弹窗、反馈和复制文本。用户界面不出现内部开发标识；必要技术详情单独呈现。不得通过删除「示例」「未连接」等必要事实来伪装生产能力。
