4. **设计与资产（RP-17–21）**：统一输入策略、方法、资产、原图审查及扩页入口。规范可读不能替代真实消费；旧整图参考不自动证明设计一致。

6. **其他性能与联合验收（RP-26–30）**：按热点和模块边界交付；F6 的兼容检查随每个相关 PR 执行，RP-30 只汇总集成，不将兼容风险推迟到最后发现。

不新增逐页审批或一个大而全的门禁；不重做已被用户认可的图片→SVG→PPT 转换链。原有取消、晚到、原件不可变、权限、真实调用消耗和身份绑定保护继续成立。
