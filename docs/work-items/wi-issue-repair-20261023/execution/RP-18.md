## Diagnosis and repair

- Independent Review preparation sent the same three content units even when
  Speech was selected. The UI now maps the selected phase to its actual review
  units; Speech sends only `speech`. Content Speech preparation also uses phase
  defaults instead of the broad Content entry list.
- Copy previously supplied only selected IDs and an unrecoverable digest. It now
  includes a readable versioned JSON packet with effective role/kind/intent/phase,
  review units and request scope; project/revision, phase state, explicit/default/
  dependency IDs, ordered resource paths/hashes, and the exact preview request.
  The existing preview/resource endpoints support rechecking and reading the
  declared bytes. Changed basis or resource bytes still refuse fixed reads.
- No new project phase made all instruction resources unselectable, and the UI
  hid them. All catalog entries now remain visible with their selection reasons
  and separate on-demand read controls. Reading a registered readable resource
  can omit an initial hash; the response reports its observed hash. Explicit hash
  reads still verify exact bytes. The catalog digest, path restrictions, 1 MiB
  limit, UTF-8 validation and unreadable-resource refusal are unchanged. Listing
  still does not read unselected bodies.
- New blueprint dispatch consumes visual-reference/physical-units/content-to-visual;
  reconstruction keeps blueprint-svg. Compose design/production phases now include
  content-to-visual. Responsibility entry guidance remains broader by purpose.
  The RC3 selector and stored manifests remain unchanged. Existing byte-change
  detection and formal reissue retain scope and authorization; reads never append
  current defaults to frozen Tasks.
