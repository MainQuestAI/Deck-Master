## Diagnosis and repair

A real 30-page studio cold read recorded 27 unfinished image-pool evictions,
zero cache hits and seven thumbnail-file requests for six final visible tiles.
Gallery layout synchronously disposes and remounts tiles; immediate zero-pin
removal aborts the shared unfinished entry before the same image reacquires it.
`ImagePool.release` now rechecks pins at the microtask boundary. Same-turn
remounts share the original promise; real departures still abort before the
next task. Identity keys, SHA references, network/decode limits, cache caps,
error UI and stale-result fences are unchanged.

The new actual Chromium regression **fails on baseline** (`shared == false`)
and passes on candidate. It also verifies warm reuse, zero leaked pins and
AbortError/empty pool after a genuine departure. No simulated HTTP image is
used: the image and thumbnail endpoints are real loopback services.
