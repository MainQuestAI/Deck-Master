# Web UI 可用性与截图视觉规范

本规格落实已批准的 WQ01–05，基线为 main `6996a29b1792e39199cf0ae968deaaaba381d9e1`。保留浅色工具视觉和已认可的内容；采用前当前稿保持不变。实现和工程检查不等于用户视觉认可。

## 工作区

比较画布使用预览自身像素定义 100%，默认适应实际可用区域。两侧缩放和平移可同步；同步平移以归一化画布中心为依据。全屏使用剩余高度，采用区独立占位。当前 SVG、候选 SVG、当前实际 PPT、候选实际 PPT 各有独立状态；工具、字体、渲染失败均提供对应的下一步，不用 SVG 冒充 PPT。

单页默认阅读，批注模式与阅读互斥。候选列表通过画布附近紧凑入口展开，意见输入靠近作品。来源、原始执行证据、恢复文件放入详情；模式切换、视图更换和全屏退出释放图像资源。图像池上限维持网络 6、解码 2、缩略图 60、大图 4。

历史以固定 head 分页，默认只显示相关页面正文或产物引用真实变化的版本；可切换全部记录。展示动作、影响页、图层、摘要和提交时间。旧记录无可靠时间显示“时间未记录”。项目创建时间保留，不能替代提交时间。

390px 画廊默认单列连续阅读、筛选折叠，隐藏列数选择；不覆盖用户桌面列数偏好。页面和工作区避免嵌套阅读滚动。桌面风格已选状态同时可辨认参考、首个目标、短要求和主动作；其它目标及高级输入折叠。

交接明确区分保存、待接手、已接手、结果返回、采用和检查。只提供一份完整 Agent 指令；复制不启动任务，也不改写接手事实。依据变化提示影响与下一步，不自动宣称所有页面需要重做。

## 截图闭环

PNG、JPEG、WebP 单次选择 1–5 张，单图最大 64 MiB、3200 万像素。保留原始字节及摘要；旋转校正、缩略预览属于派生文件并保留透明度。拒绝动画、无效解码及超限。参考登记独立于业务材料和页面可用资产。

`style_analyze` 任务固定参考资产、简短要求及项目字体，要求 `visual_reference` Host capability，生图额度为零，分析任务不能分配或开始图像调用。结果沿用任务领取、回执、取消和迟到保护。

`visual-style-spec.v1` 包含配色、文字层级、构图、间距、密度、线条、图标七维规则，各附参考位置、观察和不确定说明；字体只作近似建议。核心生成安全、显式几何的 SVG 拆解示意，不能执行 Host 提供的任意 SVG。多图冲突要求选定参考重新分析，不能仅声明主图后确认混合结果。

用户可编辑规则后确认 v2 配方。默认借用配色与文字层级，其余必须明确选择；编辑后的规则是执行依据，不把原始配色继续注入生成请求。字体使用项目注册并已安装的选择。读取 v1 不迁移、不改变其已有行为。

Builder 试作固定目标 Page、当前目标原图和参考截图。第一张是目标原图，其余是风格参考；目标原图变化时，领取、freeze、begin、结果提交与采用都拒绝过期任务。保持普通不带该标记的试作行为。自己采用后可作为同一配方扩展样例，后续其它原图变化使该资格失效。

先试作并采用一页，才允许明确选中的其它页扩展。候选列表按确切配方摘要过滤；外形相近或历史曾采用不能替代当前样例依据。参考文案、数字和品牌不成为目标内容。每页独立候选，批量采用沿用原子版本检查。

## 版本与事务

新增最低写入版本 `workbench-quality.v1`。读取旧项目不写入；首次正常事务写入新提交时间或截图字段时提升边界，旧写入器拒绝。更高边界接受现有图标、内容和风格功能；Store 禁止降级。

二进制入口独立于 JSON 请求上限，验证同源 token、长度、格式、版本和操作 ID。丢失响应先核实同一回执，重试保持相同字节与摘要；版本冲突保留输入。确认前不改变 Page、原图、SVG 或整稿输出。
