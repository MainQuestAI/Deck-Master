## 范围与证据

检查使用 `docs/design/webui-opendesign-20261001/index.html` 及其样式、资产作为视觉来源，保留浅色中性表面、黑色主动作、无衬线产品字体和事实状态。来源原型有 24 页，独立验证工程有 30 页；页名、内容及候选状态有意不同，不能将其当作逐像素内容比对。外部截图规范是新功能，按已批准的流程及现有视觉系统核对，不声称原型已有对应完整状态。

真实 Chromium 视口为 1280×800、1440×900、390×844，`deviceScaleFactor=1`。首轮保存 7 个界面各 3 个尺寸，共 21 个实现截图及对应来源截图；组合图把来源和实现置于同一画面，并查看了全图与聚焦图。原始截图、组合图、几何记录和运行日志保存在仓库外的 Design QA 证据目录；本报告只记录文件名及合成工程事实。

检查界面包括：总览、画廊、SVG 意见、候选比较、已选项目内风格参考、外部截图已分析规范及刷新恢复、任务记录。外部规范及候选通过真实核心存入独立合成工程，用于检查 UI 状态；它们不是本轮真实 Host 分析或真实业务修复的证据。

优先浏览器入口尝试结果为：IAB 不可用，Chrome CUA 连接超时。因此采用项目既有的 Playwright Chromium 验证环境，打开独立服务完成实际页面截图。没有操作用户现有服务或客户工程，不将此记录称为原生 IAB／macOS 验收。

## Impeccable 审计

采用 `audit` 路径，执行一次批量检测和首轮视觉检查，修复后只做一次确认，不扩大到无关品牌重设计。检测器报告 2 个 `side-tab` 警告，来源为已有状态／比较区域的左侧强调线；结合画面属于有业务语义的局部提示，未升级为阻断或删掉既有视觉语言。检测器输出不是设计认可。

| 维度 | 当前检查 | 边界 |
| --- | --- | --- |
| 可访问性 | 模式、草稿和候选入口保留实际键盘控件，回归覆盖焦点与保存 | 未执行 VoiceOver 或身体触屏手势测试，不宣称 WCAG 全量合规 |
| 性能 | 画廊保持虚拟化与图像池，行为测试检查6/2/60/4上限 | 本审计未重跑300页压力、20分钟长跑或业务首屏计时 |
| 主题 | 明亮中性表面和黑色主动作与现行设计一致 | 无深色模式需求，不将其作为不足 |
| 响应式 | 三种视口无横向溢出；窄屏画廊可连续阅读 | 桌面单页与风格阻断均经最后截图确认关闭；窄屏单页顶部操作仍较密集，后续可继续简化 |
| 完整性 | 实际 PPT 状态与 SVG 明确区分，旧引用及个人输入保留 | 候选字体错误说明经最后截图确认关闭；真实业务链另行验收 |
