## F01：从源声明验证实际输出

1. SVG 解析统一处理 `stroke-linecap`、`stroke-linejoin`、`stroke-miterlimit` 的继承与覆盖。复用现有 DrawingML 出口，不新增第二套图标转换器。
2. “图标仍可见”限定为工程上可证的非零描画：有效透明度、填充或描边，以及实际几何；不以形状数量或包围框代替。保留合法的多子树合并和空辅助子树。
3. 重写目录探针的预期来源：直接断言 Lucide 的 round 声明，避免以被测解析器输出证明解析器正确。

验收：

- 根、分组、多层继承、局部覆盖、local use 均覆盖 round/butt/square 和 round/miter/bevel；两出口 PPT ZIP 回读与源声明一致。
- 24 图标全部转换；正常尺寸和放大的真实 PPT 局部截图验证圆端点、连接、线宽和裁切，不用整页相似度替代。
- 全透明、有效填充/描边均为空被拒绝；部分辅助树为空但图标可见仍通过；拒绝后无可采用候选、当前稿和原图不变。

## F02：保持比较对象和任务身份

1. 同缓存身份下的新 queued/running 检查优先于旧 failed 报告；新结果覆盖前保留旧报告为历史信息。重复请求仍去重，不能误用其它候选或工具链结果。
2. 局部画布获得焦点时，方向键只作用于局部阅读；阅读标题仍可翻页。切换 SVG/实际 PPT、缩放和关闭后恢复焦点。
3. 样例草稿保存稳定候选身份和图标序号，恢复时重新核实；旧下标草稿无法无歧义恢复时要求重新选择，不默认选另一个样例。
4. 区分没有提议、提议过期、已确认和已派发。过期提议保留意见与固定比较，提供重新定位入口，不自动扩大范围或重新派发。

验收：

- 注入一次可缓存失败，重试显示 queued→running→ready/failed，自动更新；刷新、多窗口、重复点击和服务重启均给出真实状态。
- 实际浏览器 Tab 到 canvas 后左右键不改变 page/candidate/revision；三尺寸与正常/放大模式通过。
- 原样例删除、被替换、列表排序/增加及同义不同样式样例并存时，草稿仍指向同一个对象或明确失效；交接 payload 不静默改变。
- 跨页选择仍默认全不选，所有选中页各自候选、单页冲突时整批不采用；已采用结果不因 UI 恢复被重放。

## F03：让总览回答“现在真正要做什么”

1. 将个人已读状态作为独立阅读投影供任务面和总览共用；可复用已有个人状态存储，先明确 schema/兼容/清理规则。禁止把“已读”写成任务完成、候选采用或质量通过。
2. 以任务身份及结果摘要绑定已读；结果更新重新提示。总览数量、目标列表和“需我处理”应一致，个人状态清理后允许恢复待读。
3. 对真实稿的“27 页原图依据变化/SVG 待核实”提供具体依据和处理入口：显示变化的层、已有输出是否可读、可采取的查看依据/重新检查/已有试作入口（不新增保留旧产物业务事务）。不能改写历史 provenance 让界面全绿；缺少证明时保持待核实。
4. 内容大纲间距移到 CSS 类；浏览器检查记录 console.error 与 CSP violation，并区分预期错误测试，保留当前 CSP。

验收：

- 标记一项已读→任务列表/总览目标同时减少；重开仍一致；新结果只恢复对应项。历史快照和业务 revision 不被阅读操作改变。
- 同一 30 页工程中，用户能分辨“候选待决定”“需要重新生成”“历史依据待核实”“已有最终输出”；每项能直达准确对象。
- 真实六章内容页不再产生内联样式 CSP 错误；两桌面与窄屏无整页溢出，旧 keyboard/focus/草稿保护回归通过。

## F04：同一版本的工程与真人验收

工程侧：完整核心、必跑浏览器、实际渲染、wheel/sdist/隔离安装、旧写入器拒绝和当前 PR head CI。复验三用途导出、恢复和原子采用。局部比较/跨页状态或图像生命周期变更涉及性能时，按原 300×5×3 样本与 20 分钟门复测，图像池上限仍为 6/2/60/4，不降门槛。

本机侧：诊断原生目录选择的实际错误，分别覆盖成功、取消、超时/权限失败及手动输入；只在获授权的本机环境操作，不把 Linux 或 mock 结果记为 macOS 成功。

真人侧：

- 第 6/29 页候选明确采用或保留；如保留，两轮采用验收换为获认可样例，不能把“保留”改写成“采用”。
- 记录使用者是否能在 30 秒内指出当前项目状态及下一动作，不由 Agent 代答。
- 对修改后的图标查看原图/当前/候选及实际 PPT 局部，记录认可或具体需调整项。无明确回应保持待确认。

交付：准确基线/候选 SHA、合并后 CI、各缺陷关闭证据、当前 open 项、私密证据索引。工程通过、内容认可、图标视觉认可、用户使用验收分别给结论。
