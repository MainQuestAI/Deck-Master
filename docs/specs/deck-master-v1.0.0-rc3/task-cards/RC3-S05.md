## 触发与最小范围

`operations.show` 得到真实 typed not_found；原 supplementary reconcile 仅消费

新增独立 pin 的工具只支持原 q3q4 scoped run 中精确 `changes.commit` 与其失败
`operations.show` key。Root 前瞻 admission 绑定 own Python/完整安装、原注册、
run、项目、operation ID、原 payload/digest、原 intent/error 与 current revision。

## 验收边界

1. 只从该 own Runtime 的真实 typed operations.show 和 current public state
   建立观察，不信 caller result。支持的业务 not_found 需原 EligibilityBlocked
   precommit error、同一 base/current、完整可读 Task/调用事实；裸 404、timeout、
   来源不明、错误身份/operation/payload、过期、变更或 prior inflight 仍 UNKNOWN。
2. 精确逐 key；旧失败 readonly query 和新实际 query failure 各有自己的记录。
   无泛清 keys。其他 unresolved mutation、reserved/inflight/unknown 调用、running
   Task 阻塞。原始错误/事件/调用消耗保留；新 reads 按原 arm 池真实计费一次。
3. 固定 read-only 入口经原 metered query bridge：view、collaboration 以及同项目
   public Run Desk listing 全分页和 same-ID show；无任意 API/callback 入口。
   复用原 Runtime write.lock 做观察至 append 的序列化，最后重绑精确证据。
4. 仅 ledger/evidence 观察；无业务 retry、grant、plan、commit、image、adopt 或
   export。新授权/当前计划/新 commit ID 要另行真实记录；缺 fidelity review
   继续阻塞，P5 一候选一调用零重试和 no-adoption/no-full-deck 原边界不变。
5. 普通中性正反测试覆盖 not_found、真实 committed lost-response、unknown、
   typed错误/JSON参数/身份/时序/锁漂移、真实公有 in-flight、逐 query key、原
   字节/限额/协议兼容；实际 own installed Python `-I -B` 中性 CLI trace 无 seam。
   不读正式 native 稿、私有 oracle/key，不跑模型/图像，不造 native/human PASS。
