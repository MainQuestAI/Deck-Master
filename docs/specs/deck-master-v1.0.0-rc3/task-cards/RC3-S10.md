## 真实问题和修复

原 immutable SVG/PPTX 的三条 meaning-column ownership finding 来自两点：
短居中 header 的 native text box 左边被当作列左边；同 atom 的两个 native
multiline carriers 经 `shapes[name] = native` 覆盖，只剩末行位置。

parser 保留原有 `data-table-id`，并在 rounded rectangle 转为 path 前保留
frame 语义；SVG/native 输出不移动。readback 按同名 occurrence 保留全部真实
carrier、native shape ID 和缺失/多出/缺 geometry 证据。完整的显式 table frame
及 full-span native 分隔线形成唯一行列网格，并先核对真实 header 归属；每个
cell 的所有 carrier 都须在其语义 cell bounds 内。原有未声明 grid 的检查仍用
原阈值，逐 carrier 判断。native rotation 使用实际旋转后的外接 bounds。

缺失/多出 carrier、缺 header/rule、不能证明唯一完整 grid 的情况明确报告
`unverifiable_table_ownership`，不会扩大容差或静默通过。`.02px` 只识别 native
emitter 的 `.01px` 退化线 extent；cell 包含判定仅允许两 EMU 的独立舍入差。
原文本/单位/notes、node/arrow、scope/source/Narrative/Plan 与权限流程不改；
不删 ID、不改现有正确 Page/SVG/PNG、不伪造 report 或 Task closure。

## R1 路径证据修复（S10-R1-F01）

独立 R1 用合法的 native customGeom 将竖分隔线缩短到表头，保留原全部
text、ID、xfrm 与 notes；实际渲染正文缺线，旧检查仍误报 pass。空/退化
rule 和空 frame 也暴露相同缺口。原误放行、失败命令与 R1 证据全部保留。

修复将 xfrm 仅作为坐标变换：先读取实际 path 的 literal viewport 与点，
再按 extent、flip 和支持的直角 rotation 映射。rule 必须是有可见实线 stroke
的单段非退化路径，且真实端点贯穿网格；frame 必须是闭合凸折线（包含现有
rounded frame 的真实折线）或无调整 rect preset，并具有四边真实线段，
每条分隔线须接到相应两边。不能仅用 path 的存在、source 类型或外框证明
实际分隔线/周边；不更改文本容差、SVG、native 输出或原正确几何。

支持范围限于 flat 2D native shape、literal 单 path、显式 srgb 实线及上述
几何。空、退化、截短、多路径、曲线、缺 stroke、非直角 rotation、group/
slide-root 坐标变换及 grid shape spPr 上的 3D 等不能证明的 native 环境明确 unverified；不推测
未知 DrawingML 的实际全页 bounds，不宣称通用 DrawingML geometry 支持。

新增真实编译的中性回归保留合法 XML 和不变 text/ID/xfrm/notes，覆盖截短/
空/退化 rule、缺失/开放/截短/同外框非矩形 frame、多路径/曲线及 stroke
缺证；另外验证 group 与不支持旋转拒绝、等效 viewport scale/flip/rotation、
原 rounded/preset frame、整个 table 平移缩放正例。真实工具渲染截短 rule 和
空 frame，并由新工程 wheel 在真实 `-I -B` 下回读；原 immutable 两页重编译
slide/notes XML 等同性继续核对。报告只关闭本次工程缺口，仍待独立复评；
不重判旧正式失败 cut，不声明完整 AC、CI 或人类通过。


## R2 周边边界修复（S10-R2-F02）

R2 已实际关闭 F01，同时用封存的合法凸八边形 native frame 发现独立缺口：
旧检查恢复真实 path 后只保留 bbox 网格，未保留斜边；Beta carrier 全部落在
真实 perimeter 外仍 pass。原 R2 readback/render/断言和 Owner 对 exact 原件
的修前误放行均保留，不修改原件或重标失败。

本次只在已验证凸 frame 子集内保留实际映射后的 perimeter。每个 header
及 cell 的每个 native carrier 四角，既须满足原矩形行列 bounds，也须处于
全部真实 frame 边的内侧；依原 winding 判断，距离仅允许既有两 EMU 舍入。
不同 perimeter 不再合并成相同 bbox 网格。header 不能证明时维持明确的
located unverifiable；cell 超出真实边时为 located ownership mismatch，并
保留 native carrier 与真实 perimeter 证据。不是广义 polygon/DrawingML 引擎。

中性同 text/ID/xfrm/notes 的四角截边用例先真实失败；修后覆盖 header 外界、
普通 body carrier 外界、multiline 末行外界。所有 carrier 实在 frame 内的
安全截角，正反 winding 都通过；原 F01 拒绝、正确 rounded/mixed-alignment/
multiline、整表平移缩放与 CQ05 关系检查保留。新 own 工程 wheel 实际
`-I -B` 回读封存 R2 原件、真实重渲染，并重编译原两页验证四 XML 等同性。
仅处理 F02；不把未观察到位移的 root/text 3D 探索称为已拒绝或新质量失败，
不声明 blanket 3D 支持/拒绝、完整 S10/正式验收或人类通过。仍待独立 R3。
