# 设计接收后的生产适配决策

采用用户现行OpenDesign设计，不再重新做视觉方案。以下只收敛样本与真实产品之间的区别。

| 设计表现 | 产品实施决定 | 责任 |
|---|---|---|
| 24页、P07参考/P08目标、8/9偏离、缺图数量 | 使用真实项目数据；任何页都能作为合法参考/目标。无质量记录显示待判断。 | B01 / A03 A06 |
| 导出/生成未连接 | 分开服务可达、当前项目动作可用、制作工具实际接手；已有导出能力真实显示。云端同步当前不提供。 | B02 / A02 |
| 浏览器本地数据、reset清任务与候选 | 收敛为本项目个人草稿/阅读设置清理，先备份和精确确认；业务项目、任务、候选、调用账保留。 | B05 / A07 |
| 模拟接手/返回/失败、示例版本号 | 只留收讫的状态参考页。产品从Python真事实投影；示例项目始终标注。 | A01 A07 |
| 正文候选对比 | 属于本轮实际新增能力；采用前不改当前Page，不能只用直接改字冒充试作。 | B03 / A06 |
| 保留当前候选决定 | 持久记录keep_current，可重新打开；返回页面不算保存了决定。 | B04 / A06 |
| 风格套用 | 复用已有固定参考与recipe；单页正向试作后扩选，未选构图退化明确显示并可保留当前。 | B06 / A06 |
| 合并/拆分的候选措辞 | 继续复用content_ops和Host content_update，但回传先存变更集候选、用户采用后改稿；当前代码接受结果即改稿的差距由B03补齐。 | B03 / A05 A06 |
| 材料补充仅文本框 | 既有inputs支持的材料路径/版本与任务要求保持；文件选择是入口，登记成功不能称Host已读取；trial影响判断先候选、采用后才更新正文和输入对齐。 | B03 / A05 |
| 原型未暴露所有已有生产操作 | 不删除delivery、整稿结构、历史恢复、恢复文件等既有能力；按需展开到对应工作面。 | A05 A07 |
| sans产品与base衬线token | 使用产品覆盖；合法系统字体回退必须离线，不能仅因token写了字体名就复制字体二进制。 | A01 |

功能范围仍是可视化制作链：没有独立模型执行器、Web聊天、自由排版器、云端同步、PPT外部修改自动回写。新增能力必须落在现有Store、Task、operation与schema体系。
