# r3 精修与本轮证据

## 从 r2 到 r3

沿用已认可的字标、灰阶、字号、按钮尺寸和阅读节奏，未改已有 r2 或产品根原型。本轮新建独立场景样本，在同一套细节上验证完整导航与复杂交互。

| 内容 | r2 | r3 本轮 |
| --- | --- | --- |
| 工作面 | 总览、页序、单页三样页 | 项目入口、5工作面、共享单页、候选比较8场景；单页不再占一级导航 |
| 来源 | 打开模态来源框 | 单页旁展开来源并保留正文；多选共同来源明确所选页范围 |
| 编辑 | 440px抽屉 | 保留抽屉，可展开880px长编辑；关闭保留本次内存草稿 |
| 候选 | 尚无完整样本 | 同页同层基准/候选对照，采用/保留决定，影响说明与待核对状态 |
| 版本 | 示例固定R18 | 采用/编辑更新示例当前版本；历史比较固定R18；改变基准后禁用直接采用 |
| 行内菜单 | 原生details + 普通按钮列表 | 保留真实disclosure语义，补上下箭头、边缘定位、关闭回到可见summary |
| 全稿 | 无独立工作视图 | 缩略稿/连续阅读切换；缩略稿保持排版示意标识，不冒充实际原图 |
| 任务与交付 | 无独立工作视图 | 演示已返回/未提交/未检查/不可导出；真实4分区要求见SCREENS |

独立源码审查发现8项具体问题并已修正：采用按数组索引导致重排写错页；采用后版本与状态不一致；差异计数遗漏一段；多选来源误用当前页；从预览打开来源不可见；菜单进入编辑后焦点返回隐藏按钮；ArrowUp首项计算错误；窄屏翻页目标被覆盖为36px。

设计与工程交叉审查另纠正5项方案问题：保留engineering导出用途、风格扩展阶段、空项目进入输入、工作笔记/个人恢复入口、采用前后版本表达。它们已写入正式规格，未通过扩展视觉样本范围假装实现全部能力。
