## 本轮确定的方案方向

1. **项目入口 + 五工作面 + 共享对象页。** 单页是深入某个对象的工作面，不占用第六个一级导航；正文/原图/SVG/PPT 属于同一页的层，不散成多个产品入口。
2. **四类元素各有样子。** 导航负责去哪里，切换负责看什么，按钮负责做什么，状态负责发生了什么。文字链接有持续可识别的样式；不再使用无轮廓大字承载执行动作。
3. **动作跟随对象与任务。** 页面默认最多一个黑色主行动，普通列表每行最多一个操作菜单；批量栏在选择后出现。模态编辑期间背景不可操作，主行动转移到编辑器。
4. **来源、编辑、比较使用不同空间。** 来源通常在正文旁检查；短编辑用抽屉，长编辑可展开；跨版本和图稿比较使用宽工作面。抽屉不承包所有复杂任务。
5. **视觉与真实状态共同收口。** 保存、提交、复制、接手、返回、采用、检查和交付保持独立。功能迁移以既有交易/草稿内核为基础，不能把完整工作台替换成静态参考页。

本方案现为实施基线。实现按当前业务合同落地，具体差异与验证结果记录在实施台账。
