## 最后一轮修正

- 历史请求下的候选可以显式进入预览；系统推荐仍只选当前对象。采用时继续执行已有请求、范围与基准检查。
- 总览保留一项主行动，默认显示两类次要事项，其余折叠；所有固定对象入口仍可访问。
- 定时刷新保留同一对象菜单的焦点。对象身份改变时，不把 Enter 移交给另一个操作。
- 方法准备等待草稿恢复完成才开放上下文选择；预览返回时保留同一勾选控件，稳定 ID 不随显示标题变化。
- 窄屏阅读取消工具栏之间重复留白，维持 44px 触控目标；原图位于首屏。
- 新版本出现时撤下旧编辑计划的确认动作，继续保留和编辑草稿；必须重新核对基准。
- 可选面板不再把 JavaScript 布尔值显示为 `false`；截图回归覆盖此类意外文字。
