# 设计基线与整体结构

## 1. 解决什么问题

上一轮已经改善按钮大小、行内动作和单页阅读。仍需防止三个问题复发：不同工作面各自定义组件；把信息、状态与命令都排成等重的一行；为获得干净截图而隐藏重要功能。此次以“正在处理的对象 → 当前视图 → 可执行动作”组织全部页面。

用户的直接反馈是层级混乱、线框感、浮动文字按钮、按钮又大又密。视觉系统对这些反馈承担直接责任；候选资格、待办当前性、请求恢复等行为问题必须由现有修复任务提供真实事实。不得用新的文案掩盖错误投影。

## 2. 设计决定

| 编号 | 方案决定 | 原因与边界 |
| --- | --- | --- |
| D01 | 保留原 SVG 字标、浅色中性、黑主按钮、系统无衬线 | 沿用认可方向，不改品牌；不新增字体/CDN/装饰动效 |
| D02 | 稳定五工作面，单页是对象深层页 | 降低导航重复；总览和任务可直达同一页，返回恢复来源位置 |
| D03 | 普通动作 32px、主要动作 36px；编辑输入和触控命中 44px | 是拟替换旧统一44规则的明确变更；不是 WCAG 推荐尺寸或已批准的根规范 |
| D04 | 一个页面上下文最多一个黑主行动，无合适下一步可没有 | 主要步骤明确；选中/编辑状态重新分配行动，不机械在每区加主按钮 |
| D05 | 普通行一个末列菜单，标题进入对象，复选框只选择 | 保留发现性；禁止悬停才出现唯一入口；复杂制作层可有一个明确次动作 |
| D06 | 批量只作用于明确选择，切筛选保留并显示外部数量 | 沿用 D1 项目决策；比较基准与参考页不混入批量选择 |
| D07 | 默认阅读，编辑/标注互斥 | 不把大表单长期摆在正文上；关闭保留有效草稿，提交未知单独恢复 |
| D08 | 来源检查可非模态；编辑抽屉模态；比较使用宽页 | 布局随任务变化，不将所有事情装进同一个窄抽屉 |
| D09 | 页面、层、版本和来源身份持续可见 | 正在判断的固定版本不被后台刷新替换；内部 ID/命令按需展开 |
| D10 | 保留现有原生模块与业务内核，逐工作面迁移样式所有权 | 不引入框架、不复制静态原型业务逻辑、不增加第二套后台轮询 |

## 3. 信息架构

项目入口负责新建、打开与继续项目。进入项目后，左栏只放工作面；页首交代项目、当前对象/版本和连接事实；主区呈现工作内容。全局设置/项目管理在项目菜单；其中保留“草稿备份与恢复 / 清理个人状态”，这些动作不改变正文、任务、候选或调用事实。方法目录、任务详情与来源在有语境的入口。

| 层级 | 内容 | 持久状态 |
| --- | --- | --- |
| L0 项目 | 所有项目、新建、打开已有目录 | 最近项目；不可读原因；创建成功后恢复同一个项目 |
| L1 工作面 | 制作总览 / 内容与页序 / 整稿画廊 / 风格校准 / 任务与交付 | 工作面、搜索、筛选、排序、滚动位置 |
| L2 对象 | 某页、某材料、某任务、某候选、某版本 | 稳定对象引用；历史/当前关系；来源工作面 |
| L3 局部视图 | 来源、逐页稿、提示词、原图、SVG、PPT；读/改/标注 | 所选层与视图；固定比较引用；草稿 |
| L4 临时任务 | 编辑、影响预览、范围准备、确认采用 | 原基准、原请求、草稿 ACK、结果状态 |

产品显示名统一为“内容与页序”，其下保留“逐页稿 / 章节与计划 / 材料与来源”三个分区；原“内容与来源”路由与深链接兼容映射，不因改标签创建新业务层。一级标题是名词，操作是具体动词+对象，如“修改正文”“比较结果”“导出检查包”。

任务与交付保留现有四个业务分区：**正在进行、待决定、版本、文件**。交付检查在文件区，结果决定在待决定区；r3 简化样本的两种演示页不是实施时删减四分区的依据。

## 4. 三条主要连续路径

**内容路径：** 项目 → 总览的当前待办 → 内容与页序 → 单页阅读 → 就地核对来源 → 编辑/结构变更 → 保存结果或变更候选 → 继续下一页。正文不需要绕经任务列表才能阅读。

**制作路径：** 单页或选页 → 选择制作层 → 准备摘要（范围、依据、方法、影响）→ 已授权提交/交接 → 任务进展 → 返回候选 → 固定比较 → 采用或保留当前。复制与派发的能力分别表达；浏览方法目录始终可发现。

**交付路径：** 任务与交付 → 固定版本 → 查看该版本检查 → 修复对应问题并定向复核 → 选择导出用途 → 下载该版本文件。审查/交付/发布不合并成一个“已完成”。

## 5. 布局与密度

主验收 1440×900 与1280×800；768与390检查降级。桌面项目栏200–224px、工作区内边距24/32px、分区间距32px。阅读正文16/28，最大40rem；工具文字13/20，界面正文14/22。单页标题24/32，长标题可换行；不缩小字号挤进一行。

表格最小行高64px，长内容自然长高。横向留白16px；状态列与动作列稳定，标题优先换行。默认列表显示身份、主标题、必要状态和末列菜单，副信息只放章节/来源等帮助识别的内容。复杂制作矩阵以六层事实作入口，动作在聚焦对象之后呈现。

1280 时保留阅读主体，辅助区不应把正文压到无法连贯阅读；不足时依据区移至下方。小于800项目栏变为可换行的工作面选择，不横向遮断最后入口；小于560单列，触控44，抽屉全屏。图稿始终等比完整呈现，不用 cover 裁图。并排比较窄屏先基准后候选，标题保持。

空白承担分组，不堆空卡片。白色用来阅读，浅灰承载工具与来源；只给菜单/浮层阴影。状态色不作普通装饰；灰色不能成为降低可读性的捷径。

## 6. 状态合同

| 状态 | 页面呈现 | 可行动作 / 禁止误导 |
| --- | --- | --- |
| 初始加载 | 标明目标工作面；保留框架与本区进度提示 | 可切换导航；不把旧页当新页，不使用假百分比 |
| 空状态 | 解释没有对象或未制作的原因 | 给一个创建/补材料/切范围入口；无权限时仍解释 |
| 筛选无结果 | 显示查询与0条；保留筛选外选择数量 | 清除筛选；不能等同项目没有内容 |
| 只读历史 | 固定版本标签、时间与返回当前入口 | 允许阅读/比较/按资格导出；编辑禁用说明原因 |
| 编辑有草稿 | 字段旁显示保存位置/时间与是否 ACK | 关闭可恢复；丢响应与未保存草稿不混成一个红点 |
| 保存成功 | 当前对象显示版本和保存事实 | 正文仍按真实核对状态；不自动变已核对 |
| 保存失败 | 保留输入，就近显示可理解错误 | 同请求恢复或修正字段；不能清空编辑器 |
| 结果未知 | 显示“结果待确认”，保留原操作上下文 | 核对原操作，不自动另发重复变更 |
| 基准冲突 | 标出当前新基准与本次草稿基准 | 看差异、保留双方，明确重新应用；不覆盖新稿 |
| 已提交/执行中 | 局部进展+持久任务记录，具体对象 | 查看/取消按能力；重复点击不新建任务 |
| 结果返回 | 候选入口和待决定计数 | 比较/采用/保留当前；不替用户采用 |
| 候选不可读 | 保留候选身份与读取错误 | 就近重读；不拿当前产物替代缺失候选 |
| 已采用 | 回读新当前版本与影响范围 | 下游过期、待核对、待检查分别表达 |
| 已取消/迟到 | 保留记录，晚结果单列并解释 | 不覆盖后写内容或新版本 |
| 当前关系未知 | 标“关系待核实”，保持详情可读 | 不把旧失败升级当前阻塞，也不静默隐藏 |
| 离线/工具不可用 | 状态就近持久，已有内容继续读 | 可恢复时重试；不把所有菜单隐藏 |
| 检查未通过 | 具体发现、页/层、报告与固定产物身份 | 定向处理；通用 pass 不关闭旧发现 |
| 导出不可用 | 显示用途、固定版本、缺项 | 修复/重新检查；不可用原因不能只在 tooltip |

以上是产品实施合同；本轮 r3 只演示部分状态。真实状态覆盖不得以参考页内存模拟代替。

## 7. 内容与可访问性

每个执行按钮有可理解名称、对象和结果；纯图标有名称、焦点和稳定命中区。菜单不混用不完整的 ARIA 模式；选完整 menu-button 或原生 disclosure+普通按钮列表，按真实语义实现键盘路径。Tab 不进入隐藏控件；Escape 关闭当前浮层并返回有效入口。

非模态来源区不困住焦点。模态编辑器让背景不可操作，焦点进入并循环；长正文可展开宽编辑区，保存区固定、内容区滚动，不遮最后字段。错误贴近字段且可被读出，输入保留；长内容初始焦点可落标题。异步成功/等待使用适当状态播报，不抢焦点、不每次轮询重复播报。

用户正文、内部核验说明、来源证据分层。客户需要的限定仍留正文，内部 ID/hash/命令放必要详情；不把来源不足包装成确定结论。
