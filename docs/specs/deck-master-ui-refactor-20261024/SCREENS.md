# 逐页与共享交互规格

每页明确主问题、内容顺序、动作归属、状态和返回方式。S00–S07 是设计范围编号，U01–U05 是共享容器；不替代现有 A/B 或 RP 任务编号。r3 仅实现“样本覆盖”所列的界面示例。

## S00 · 项目入口

**用户要回答：** 我该继续哪个项目，或者如何开始一个新项目？

首屏是最近项目列表和唯一主动作“新建项目”。“打开已有目录”为次动作。项目行显示名称、最近活动、页数/阶段与具体不可用原因；名称/封面进入项目，管理项归末列菜单。不可读项目保留位置与原因，不能静默消失。搜索是本页工具，不成为全局命令中心。

新建采用短流程：任务说明 → 材料 → 保存位置。空值有解释，目录选择取消回原表单；创建成功但打开失败时显示已创建对象和“重新打开”，不能重新创建第二份。新建且尚无内容时进入材料与任务要求；已有内容首次进入总览；恢复项目优先恢复有效最近位置，总览入口始终可见。

样本覆盖：单个虚构已有项目入口。新建、真实目录选择与不可读状态为实施项。关联模块：launcher-ui/app；验收 AC01/AC02。

## S01 · 制作总览

**用户要回答：** 当前进到哪里，最需要我处理什么？

上部以真实当前待办为视觉中心：对象标题、阶段/范围、原因、下一动作。多个同等优先对象时给列表；无法可靠推荐时显示“选择要处理的事项”，不能前端猜出一个黑按钮。主区下部保留六层制作矩阵，统计是导航辅助，不用一排等大数字卡挤走任务。侧区为继续阅读、待决定候选摘要和最近活动。

当前阻塞、当前可行动、历史记录、关系未知分别组织；历史失败仍可查但不铺进当前待办。矩阵每行对应页对象，每列是内容/提示词/原图/SVG/PPT等事实；点击状态进入对应层，常驻动作不铺满每格。

主要动作随事实为“补充材料”“核对正文”“比较结果”“继续制作”之一；操作对象、范围与资格由当前性投影提供。次动作“打开上次阅读”；工具“筛选/排序”；低频“记录与详情”。新候选只更新数量，不替换当前阅读版本。

样本覆盖：2 页待核对、一个返回候选入口、继续阅读、简短记录。真实六层矩阵/多类待办为实施项。依赖 #182→#132；验收 AC03/AC04/AC05。

## S02 · 内容与页序

**用户要回答：** 整稿的论证和顺序是否成立，每页依据是什么？

三个分区：逐页稿、章节与计划、材料与来源。主视图是逐页稿列表，行内依次为选择框、页号与缩略稿、结论标题与章节、正文状态、一个对象菜单。页名点击进入完整正文；选择框仅控制批量。标题长时换行，页号和状态仍可辨。

章节与计划应能编辑章节、计划页、页目标和来源关系，变更前后在同一工作区核对。材料区显示材料版本、读取状态、关联页面、待确认事实；主线绑定、文字映射和来源链接分别表达，不共用一个“缺失”标签。上传、提取、绑定、实际消费不能写成同一种成功。

默认主动作按状态为“核对待处理页”或“调整内容计划”，不是永久“生成”。单页菜单包括改标题/正文、移至章节、上移/下移、拆分/合并/移除（按资格）；危险或跨页动作显示影响预览。合并和拆分结果先为候选，采用前不改当前稿。键盘重排与拖拽等价。

批量栏只在选择后出现，显示总数、筛选外数量及具体页清单；全选只包含当前可操作筛选结果。混合资格显示可执行/不可执行的数量和原因，不静默忽略。材料与方法详情从上下文进入，浏览方法不等于派发。工作笔记保留为内容工作面辅助入口，注明仅为私人工作笔记，不自动进入正文或任务上下文。

样本覆盖：搜索、状态筛选、选择保持、共同来源、上下移动、章节示意、编辑抽屉。计划结构变更/上传/方法准备为实施项。依赖 #133/#143/#170–172；验收 AC06–AC10。

## S03 · 整稿画廊

**用户要回答：** 整稿的叙事、节奏和跨页风格是否连贯？

画布优先，不把全部生产工具放在页首。局部控制分为产物层选择（内容/原图/SVG/PPT）和视图选择（缩略图/连续阅读/并排），不能让两者用同一组含混标签。每页保留页号、标题、产物层/状态；未制作显示缺少该层，不用正文缩略图假冒原图。

未选择时无需黑色行动。选择页后显示“准备所选页制作”等实际适用动作；参考页、批量选择、比较基准是三套独立标记。连续阅读完整展开；并排只比较明确选定对象，图稿等比完整，长文本不裁切成摘要。

进入单页后返回原层、筛选、选择和滚动位置。图片失败局部重试；离开路由停止相关读取、释放图片资源，背景新结果不改变固定引用。

样本覆盖：6 页排版示意、缩略图/连续阅读切换、进入单页。真实产物/并排/多页制作与资源管理为实施项。验收 AC11/AC12。

## S04 · 风格校准

**用户要回答：** 当前采用什么设计方向，哪些约束继承，下一步校准什么？

首先呈现当前整稿基准及参考样页，再进入四阶段：参考与目标 → 确认规范 → 试作与采用 → 扩展。当前阶段展开，历史阶段可读。“借用与保持”放在确认规范阶段；扩展阶段明确目标页、固定依据与预算。项目内五维与截图七维来源保持各自 schema，不为界面整齐合并成一套错误参数。

整稿方向、页级覆盖、自由设计范围和固定约束分别展示；冲突定位具体字段。资产显示登记、绑定、消费事实，模板文本抽取不称为母版复用。历史 V1/V2/V3 规范可读，当前选定与已确认关系明确；不支持操作仍保留阅读。

主要动作是本阶段下一步；试作前同区展示页范围、固定依据、策略与影响。先试指定页面，返回后比较采用；只有明确扩选才扩展全稿。不把未实际执行的偏离检查画成红绿分数。

样本覆盖：基准摘要、排版示意、无真实检查结果、阶段说明。四阶段真实表单与资产消费为实施项。依赖 #181→#141、#162/#164–166/#173；验收 AC13/AC14。

## S05 · 任务与交付

**用户要回答：** 正在做什么、哪些结果等我决定、哪个版本可以导出？

保留四分区：正在进行、待决定、版本、文件。每区一次只展开一个工作上下文；任务动作不得渗入版本/文件区。任务行显示职责/阶段、页范围、基准、提交/返回时间和当前关系，同名任务无需打开即可分辨。

正在进行区显示真实进展、查看详情、取消/核对原操作；待决定区统一候选卡与比较入口；版本区明确“所选版本 / 已读版本 / 当前版本”的关系，恢复产生新版本，不回滚历史执行事实；文件区把导出用途、固定版本、检查结果和下载放在一起。

审阅包、正式交付包、内部工程恢复包分别对应 review / delivery / engineering，不做一个模糊“导出”覆盖全部行为。可编辑 PPT 作为文件类型和原生可编辑性事实独立表达，不新造导出用途。缺检查或产物时显示具体恢复入口；通过检查不叫已发布。已返回、未知、取消、失败和历史任务有准确独立状态。

检查发现绑定原报告和固定产物；逐项显示开放、已修、接受差异、未核查。新通用通过记录不能冲掉旧开放发现。保持复制交接、恢复与执行详情的可发现入口，内部命令在必要详情中。

样本覆盖：返回候选、未提交制作、检查缺项与不可用导出；样本用两页浓缩表达，四分区必须在实施中保全。依赖 #150/#169/#171/#182/#186；验收 AC15–AC19。

## S06 · 共享单页

**用户要回答：** 这一页说什么，依据是什么，当前层可以怎么处理？

顶部给来源工作面返回、当前页号与上下页。标题先于工具，局部层导航依次覆盖来源、逐页稿、提示词、原图、SVG、PPT；正文阅读不被模板/资源列表挤到下方。预备提示词与实际调用输入分开命名；实际证据不可被编辑器草稿替代。

正文16/28、40rem以内；来源及制作事实在侧面，窄屏移下方。来源检查非模态，可一边读正文一边对照；未确认来源只陈述关联事实。图稿完整等比，缩放、标注和版本比较各有明确模式，不放大图片遮住上下文。

读、改、标注互斥。正文“修改”进入抽屉，长稿可展开宽编辑；意见绑定精确选段/元素范围并有键盘替代。保存稿件、提交意见、准备制作分别反馈；一项成功不能冒充另一项完成。切层、切页、返回保留已 ACK 草稿，基准冲突保留双方。

样本覆盖：全文、来源展开、正文/排版预览、上下页、编辑/展开、草稿和校验、候选提示。完整六层、标注、真实保存恢复为实施项。验收 AC20–AC24。

## S07 · 候选与变更比较

**用户要回答：** 哪个对象、基于哪版、变了什么、采用会影响什么？

宽工作面顶部持续显示页/层、固定基准与候选、来源和差异摘要。左基准右候选；正文呈现真实文本差异，图稿等比完整并排。窄屏基准先、候选后，仍明确各自身份。错误读取不能用当前稿替代。

候选采用与历史比较分开：历史比较只读；候选有“保留当前”和“采用此候选”。采用前影响区说明将变化的对象、下游失效和原始版本保留范围；采用成功后回读新当前版本。按动作实际后果决定是否需要最后确认，不额外增加逐页审批。已有授权继续执行，必要确认聚焦具体影响。

比较期间新结果不切换两端；当前基准变化时明确失效与重新核对，不能静默采用。重排改变显示页号但不改变稳定页对象。决定需真实持久回读，可按既有能力重开决定。共享组件供单页、风格、任务三个入口使用。

样本覆盖：两版正文固定对照、采用确认/保留当前、采用后待核对、编辑改变基准后禁用采用、重排后稳定对象。真实图稿/变更集/后台并发/持久决定为实施项。依赖 #139/#149/#150；验收 AC25–AC28。

## 共享容器

| 编号 | 容器 | 适用与限制 |
| --- | --- | --- |
| U01 | 来源检查区 | 就地阅读短摘录/来源状态，可非模态；长材料单独宽阅读区。不会自动把已关联改成已核实 |
| U02 | 编辑抽屉 | 440px短编辑，可展开约880px，移动全屏；标签/错误/草稿/固定保存区/焦点循环；不替换交易内核 |
| U03 | 对象菜单 | 稳定末列入口、有可访问名称；动作分组、不可用原因、完整键盘与边缘翻转；不装全产品导航 |
| U04 | 准备与影响区 | 明确职责、阶段、页范围、当前层、依据、方法、结果形式与影响；执行/复制区别；复杂跨页使用宽区 |
| U05 | 恢复与状态区 | 当前对象旁的持久状态、局部错误、原请求核对与恢复入口；toast只补充，不承担唯一证据 |
