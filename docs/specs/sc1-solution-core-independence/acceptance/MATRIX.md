# SC-1 验收矩阵

共 91 项预定义验收案例。每项主治理章节见 acceptance/cases.json 的 spec_ref 字段。全部初始为 `not_run`；这不是产品测试通过清单。L1/L2/L3 按主证据层标记，必要时补多层验证。

每项实际执行后填写代码SHA、命令、环境、输入指纹、结果、未覆盖条件和安全证据引用。不要将本包Schema自检结果填入本表作为产品验收。
