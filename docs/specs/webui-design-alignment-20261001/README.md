## 原始功能缺口与优化方案（2026-10-01 快照）

方案经源码审查后的执行顺序、契约修正与逐包验收，统一见 [开发计划](DEVELOPMENT-PLAN.md)。U00–U05 已依次完成并合入 PR83–89；下面保留制定方案时的问题清单，不能作为当前未实施清单。涉及批量范围、目标聚合、偏好兼容与测试门禁，以开发计划为准。

| 优先级 | 证据与缺口 | 优化方案与验收条件 |
|---|---|---|
| P1 | `overview.js:matrixPanel` 选择页集合仅由页面内维护，未被批量动作消费；源码仍有后续接入注释 | 增加“对所选页生成/校准”入口，复用 changes plan/commit 与 styleSelection；只传当前筛选中可操作页，确认页列明目标/层/调用上限。历史版禁写、筛选变化清选、未确认不派发；浏览器核对最终计划与所选页完全一致 |
| P1 | `overview.js:actionRoute` 将 compare_candidates 等动作落到通用 runs，没有候选级定位；summary 提供 source_refs 而非可直接导航身份 | 读模型补充稳定 destination（task/candidate/page/layer）并绑定 revision；前端打开精确对象或候选列表，损坏引用显示原因。禁止解析 ID 猜路由；点击待办后可直接比较同页同层候选 |
| P1 | 真实 Host 正向风格、30 页两轮修改仍缺证据；连接面板明确 handoff_required | 以获准材料跑“冻结请求→交接→实际调用记录→返回候选→采用→质量检查”；分别记录调用、结果与用户决定，覆盖取消/迟到/未知结果。不要把复制交接升级为处理中；不虚构一键后台生成 |
| P2 | 原型刷新偏好更完整；总览搜索/筛选/排序是局部变量，重绘丢失；画廊/阅读位置已有持久化 | 复用个人 UI 状态扩展总览偏好，按项目身份及版本隔离，URL 优先，损坏值回退；业务选择不默认恢复，防止误批量执行。刷新/跨页返回恢复过滤但不写业务 |
| P2 | 风格面仍是较长的三段表单；多目标需要大量滚动、原型更强调参考与目标视觉关系 | 在现有固定 recipe 协议上增加参考/目标缩略图、页码搜索、阶段摘要与进度；展开当前阶段，保留明确回到前一步。变更参考须使旧 proposal/plan 失效，不能隐式重试调用 |
| P2 | 内容面 `content-sources.js` 仍出现 Host 技术文案，材料影响说明与大纲层级挤在一起 | 使用“制作工具影响判断”，改成有标题的摘要块，详细依据折叠；保持“已登记/已读取/已判断/已协调”四态，不能把登记材料当作已解析 |
| P2 | B07 仍未在最终候选完成安装摘要、三用途导出、长期压力、回退及本机操作验收 | UI 变更稳定后在同一候选包验证安装/导出/300×5×3 长跑；旧 UI 移除后的回退指完整旧版本安装，不提供隐蔽旧页面。HOME 迁移、macOS 选择器与真人观察单独记录 |

建议顺序：先 P1 的待办精确导航和批量闭环，再持久化/风格面渐进呈现，最后真实制作与最终包验收。以上优化没有在本提交中宣称完成。

## 验证边界

本次定向测试和资源打包检查见 `evidence/validation.json`。首次定向测试遇到一项本次新增测试对 HTTP 404 的捕获写法错误（已修正），以及一次既有 launcher 进程退出超时；重跑完整定向集合通过。前一轮全量基线的 rsvg-convert 缺失及 Node 不支持实验参数仍存在，本轮不宣称全量测试或真实渲染通过。
