### T03.01 接收TXT/JSON完整Page切片

- [ ] 实施：实现sources读取和content整稿预校验；返回资料实际定位及全部Page，未知字段定位错误。

### T03.02 实现可见正文原子

- [ ] 实施：递归paragraph/bullets/table、标题副标题、labels/callouts/脚注；保留display_text、0、空值差异；不投影排版元数据。

### T03.03 规范稳定ID和正文关系

- [ ] 实施：缺ID只分配一次；旧Pointer在导入时解析成atom；修改/重排保ID，复制新ID；拆合显式映射。
- 交付与核对：atom-identity往返成立；同字条目不误合并，删除ID不复用。

### T03.04 统一设计与资料引用

- [ ] 实施：规范style/font/asset、用户本地asset到真实Artifact；解析Page覆盖和许可子集；读取已存extract不依赖原hash可得。
- 交付与核对：design_context可供Host/编译/UI共用，指定Logo/字体可追溯且不外发受限资产。

### T03.05 补齐MD/PDF/DOCX/PPTX读取

- [ ] 实施：选择现有可用解析工具，保留表格及页段位置；纯图页交实际阅图；缺工具返回具体待处理格式。
- 交付与核对：六种资料各有内容样例；尾部只读约束能进入实际输入，未读内容不写已读。
