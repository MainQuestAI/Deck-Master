- 交付与核对：真实调用前停止生效；未知调用保留，不以取消重新获得名额；完整恢复矩阵在T13.06。

### T13.05 完成并发与工具证据回归

- 交付与核对：仅承诺约束产品协议请求；缺工具回执标host_reported而非provider_verified。

### T13.06 补全恢复与冲突结算

- [ ] 实施：在T12完成后验证restore/retry不重获名额，settle冲突拒绝；保留多轮历史。
- 交付与核对：恢复前后实际消耗与未知状态不回滚，当前和历史产物均可追溯。
