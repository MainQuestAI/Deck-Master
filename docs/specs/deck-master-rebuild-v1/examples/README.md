# 合同与完整往返示例

本目录所有企业、数字、配置、素材和审阅均为合成文档示例，不是实际Host调用、PPT制作或业务验收。五个顶层JSON分别匹配既有五类合同；synthetic-project提供实际可校验文件hash与项目Ref，字体只有名称配置、不附字体文件。

[v1.1完整往返例](roundtrips/README.md)覆盖缺原文、设计权威/资产移动、稳定atom、fixed复查、临时结果信封及调用名额。无效例有invalid前缀，必须在所注明格式或语义层拒绝，不能因schema允许部分结构就推断产品会放行。

[content-pair.md](content-pair.md)是方法正文范例；[host-task-prompts.md](host-task-prompts.md)是宿主指令草案；二者不抵扣D1/D2真实默认成稿运行。[cli-session.md](cli-session.md)所有命令均待实现。
