# D01 作者策略和业务框架的最小合同

[套件入口](../README.md) · [唯一执行状态](../execution-index.json) · [总方案](../SPEC.md)

迭代：I1。前置工作单元：D00。当前未实施；验收不得根据文档编制完成而勾选。

**目的：** 为商业任务、框架和后续修改建立准确且可兼容的承载。

**实施：** 增加 Narrative.v2 与能力协商；原始输入留在既有 task 字段。定义业务主题与命题的区别、框架节点引用、策略取舍和方法作用引用。新策略绑定实际使用的 brief、scenario、existing_decisions、audience 等输入；必要时扩展现有依赖切片注册。

**代码落点：** models.py、content_production.py、dependency_slices.py、collaboration_binding.py、content_insight.py、resources/contracts、各 Narrative 消费处。具体路径和实现需要 Codex 核验。

**验收：**

- **D01-AC01** 新旧 Narrative 均能按真实版本读取，旧内容不被补造新字段。

- **D01-AC02** 新任务要求新能力，旧 Host 不能无声降级或丢失字段。

- **D01-AC03** 只读旧项目不提升 writer floor；首次持久化新语义按规则升级。

- **D01-AC04** 场景或已用共识变化后，旧策略不能继续被自动当作当前有效。

- **D01-AC05** 确认稿、write_only、speech_only、design-only 不被强制重新策划。

- **D01-AC06** 采用、失败和恢复继续绑定正确对象、版本和范围。

- **D01-AC07** plan_only 完成后保留原关闭请求；需要正式采用/审查时复用有界后续请求，现有采用路径登记 Narrative.v2，无需新增采用状态机。

**依赖：** D00 方向成立。D03 至 D07 共同遵循此卡的真源与兼容约定。
