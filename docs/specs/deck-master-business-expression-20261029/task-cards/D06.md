# D06 作者任务和框架工作流

[套件入口](../README.md) · [唯一执行状态](../execution-index.json) · [总方案](../SPEC.md)

迭代：I1–I3。前置工作单元：D06a、D06b。当前未实施；验收不得根据文档编制完成而勾选。

**目的：** 让上述能力在作者实际工作中可用，避免后台做完、作者仍只能逐页猜测修改。

**实施：** 沿现有入口增加自然语言商业任务、作者目标、已有共识和既定框架的表达。复用真实 Narrative 比较/采用，突出框架含义、需求与能力对应、取舍、场景和待定问题。接入策略影响预览。普通作者看到业务问题和建议，高级方法细节可展开。

**代码落点：** launcher-ui.js、content-sources.js、insight-reading.js、content_insight.py、method-library.js、content-edit.js、current-work.js 及对应 API 投影。

**验收：**

- **D06-AC01** I1 即可完成“输入任务—读策略与框架—采用或修正”的最小闭环。

- **D06-AC02** I2 可以完成“改变重点—查看影响—得到重编结果”的闭环。

- **D06-AC03** 旧项目没有框架时显示未记录，不阻止阅读和合法局部工作。

- **D06-AC04** 用户已经确定框架时不强制重新发明或反复确认。

- **D06-AC05** 方法建议、冻结、执行、成果、审查状态按真实事实显示。

- **D06-AC06** 切换历史或比较候选时不混入其他版本的内容。

- **D06-AC07** 沿用当前设计系统，不扩展为一次全面视觉改版。

**依赖：** 分批随 D01 至 D05 实施，I3 收口。

## 执行顺序与增量边界

D06a 在 I1 实现最小任务输入/框架阅读投影；D06b 在 I2 接入 D03/D05 的真实采用和重编；I3 收口空态、错误、恢复和历史。编辑前读 DESIGN.md 与其当前 UI 增量。

浏览器首验为本机 Mac、1280×800 与 1440×900，窄屏按当前设计降级。mock 画面不替代真实写入及版本绑定验证。

## 具体交付

任务输入、框架阅读采用、影响预览与重编闭环的真实浏览器证据；含旧项目、历史候选、窄屏与键盘操作。
