# D07 固定版本作者包与有界接续

[套件入口](../README.md) · [唯一执行状态](../execution-index.json) · [总方案](../SPEC.md)

迭代：I3。前置工作单元：D04、D06。当前未实施；验收不得根据文档编制完成而勾选。

**目的：** 不等排版，作者便能拿到可讨论、可准备讲述的成果。

**实施：** 从选定的固定 Narrative 和匹配 Plan 派生作者包；有 Page 时附逐页正文与既有讲稿，有演示职责时附随页提示。复用既有完成、导出、下一动作和 Host 交接。复制交接保持待接手，不冒充已执行；不另建通用 Host 平台。

**代码落点：** exports.py、content_insight.py、content_plan.py、delivery-desk.js、current-work.js、change-handoff.js、现有导出合同与读取保护。

**验收：**

- **D07-AC01** plan_only 在零 Page 时也可交付真实策略、框架和计划职责，不制造页面。

- **D07-AC02** 未采用候选可只读导出并保留真实状态；导出不代替采用或审查。缺少匹配 Plan/正文时明确缺项，不借用当前其他版本补齐。

- **D07-AC03** content_full 导出完整内容及已存在的讲稿；讲稿继续由 Page notes 提供。

- **D07-AC04** 导出候选 A 或历史版本时，不混入当前 B 的 Plan、正文或讲稿。

- **D07-AC05** 作者包与客户包用途明确，内部策略、方法与未确认信息不误入客户成品。

- **D07-AC06** 导出是读取投影，不触发写稿、生图或额外 Host 调用。

- **D07-AC07** 内容-only 正常完成，不被抬成必须制作 PPT。

- **D07-AC08** 局部修改和 speech-only 不重开全局策划。

**依赖：** D01 明确真源，D04 形成内容，D06 提供可用入口；I3 完成全流程检查。

## 执行顺序与增量边界

先冻结导出输入引用及用途，再从真实对象派生；以候选 A/当前 B、缺 Plan、零 Page、speech-only 四组验证不混稿；最后接入现有交接与下一动作。

复用现有状态、不可变对象与作用域约束，不另建同义生产或审批链。

零页面策划包、完整作者包、候选/历史缺项样例，固定版本索引与读取无副作用证据。
