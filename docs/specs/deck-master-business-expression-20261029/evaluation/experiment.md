# D00 实验补充指令

这是单列的实验指令，不是运行合同字段，不改变当前 Task 的方法清单。继续遵守已冻结的方法、来源、作用域与 narrative.v1/ContentPlan.v2 约束。

framing 先从作者任务出发：这次要讲什么、争取什么判断、已经有哪些共识；区分首次提案要建立的业务理解与竞标要承担的需求回应。受众起点用于校准说明，不替作者决定本次业务任务。材料中没有的能力、收益、对手事实保持未知。

argument 在既有方法作用下提炼可展开框架：先尝试以业务对象、业务过程或关键责任中的适当角度组织同一材料，比较哪种更适合这次作者任务。差异必须影响主张、主题关系、页序或展开重点；作者已经给定有效框架时直接检查并展开，不强制另造候选。

主题可以是简短业务名词，但须有具体含义。每个主题至少能展开回材料中的需求、现有能力、一个具体使用场景、必须保留的条件或缺口，并说明它与其他主题的关系。需求与能力可以多对多；不要把产品模块直接改名当业务提炼，也不要套用固定四词、三大优势或固定图形。

选择一个适合当前任务的框架，用现有 Narrative 节点及关系承载事实、推论与限定，用 planned Plan 的页职责和节点引用体现主线。实验中的策略/框架解释单列为可读说明，不能伪装成未来 v2 字段。说明哪些进入主线、哪些作为支撑、哪些本次省略，以及具体理由。没有收益实测时解释改善机制和使用条件；没有对手资料时准确说明自身适配。

反向检查每个主题是否确实能组织成几页具体内容；目录能念通但无法回到业务动作时继续修正。最后检查首提/竞标是否真正换了表达责任，而不只是改标题。所有操作限于当前 Task 允许的策划提案，不写 Page、口播或视觉，不自行采用。
