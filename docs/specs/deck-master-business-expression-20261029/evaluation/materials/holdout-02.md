# 合成留出输入 H02：营销内容规范自查

本材料为原创合成输入，仅作 D08 留出评测，不得用于开发提示、方法调整或选择最好输出。

一家多品牌企业的区域市场人员用不同尺寸图片制作活动物料，品牌团队逐件核对标识、必需声明与禁用词。没有给出识别准确率、审稿时长或违规损失的实测数据。R1 按品牌和地区选择适用的已发布规范版本，R2 上传图片得到可定位的问题线索，R3 品牌人员确认问题后给出修改意见，R4 保存原件、所用规范版本和人工处理记录。

现有产品 C1 可上传 PNG/JPEG 并保存不可变原件，C2 可提取文字与标识位置并生成候选问题，C3 可选择规范文本版本，C4 可将人工意见绑定到图片区域并保留复核结果。当前没有训练并验证过的法域法律判断能力，没有证明能够自动理解全部品牌例外，也不自动批准发布。不支持视频逐帧审核。原图识别不一定可靠，最终品牌与法务责任留给相应专业人员。

可用演示规范和图片展示上传、选择版本、定位疑似问题、人工确认和修订记录。演示是受控样例，不提供商业准确率。建议先覆盖一个品牌、一个地区的静态活动图片；实际检出与误报需独立标注样本核对，门槛待定。企业现有发布系统保留，接口只在另行确认后开发。没有对手资料。

首次提案尚需说明自查怎样帮助一线改稿以及人工终审如何衔接。竞标已确认采购辅助自查，重点考察规范版本、问题定位、复核责任和发布系统边界，不再进行通用品类教育。
