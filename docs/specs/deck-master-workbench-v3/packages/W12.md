按DX-SPEC§6/§7验证最终安装包内文档与真实命令一致；新命令只在对应卡实现后改标可运行。统一deck-master命令面和现有退出码，不新增deck命令、SDK、Node构建工具或遥测平台。复用dev依赖中的Python Playwright，将真实本地服务浏览器资源/下载检查纳入CI可执行门禁；真实Host另列人工记录。registry、项目、安装位置均隔离临时目录，禁止测试触碰真实项目或实际HOME安装。首次成功测量从安装文档起点到理解只读样例，安装下载/前置环境/真实Host耗时分栏，≤5分钟只是待实测目标。

不引入新平行schema；核验各包协议版本、旧项目读兼容、新writer最低版本。release manifest把code/静态资源/Skill/schema绑定同一候选；安装失败补偿延用现有install机制。测量不改变生产状态：返工轮次按首版返回后为纠正同页而发起的一组请求记，图像/SVG分别计，完成/失败/取消分别列明，传输重放不重复计；手修PPT页数来自用户实际人工编辑记录，无记录标未知，不能自动宣称零；Host等待按提交至接手、接手至返回分段记录，以真实时间戳为准。首批数据只作为基线；若无可比对照或模型/内容/环境不同，说明差异而不归因给UI。
