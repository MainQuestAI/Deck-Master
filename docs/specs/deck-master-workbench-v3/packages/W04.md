# W04 · 24页整稿画廊与制作矩阵

状态：设计提案，未实施、未验收。执行基线：d1c7c4600cb0fc781070116ed8cc8a1ff6b8b7ca；产品真相见 [PLAN](../PLAN.md)，当前实现见 [CODE-BASELINE](../CODE-BASELINE.md)。

## 用户结果

二三十页可以一次看：先发现整稿节奏、风格偏离与缺图，再进入有问题的页，不再逐文件打开图片。

## 范围与不做

制作总览页×阶段矩阵；原图为默认同层画廊，2/3/4列联系表、连续阅读、2–4页并排；按章节/缺失/失效/意见/参考筛选。跨筛选保留选择，按hash缓存缩略图，大图懒加载。

不做：把同层缺图用其它阶段补位、默认混合最佳产物、无限节点画布、任意页面自由排版。

## 依赖与拆分

依赖 W01、W03。只有读取和个人选择状态，不等W07才能交付价值；标参考可先是个人选择，正式Recipe由W08负责。

## 契约与服务复用

工程约束见 [ENGINEERING-SPEC](../ENGINEERING-SPEC.md) §6：固定300页×5候选×3Attempt压力，30页首屏≤2s；共享图像队列≤6 in flight/≤2 decode，内存LRU最多60缩略图/4大图（含可见/预取/比较）。cache key是project+hash+variant；新原图入库后后台派生缩略图，旧图渐进生成，冷/热分开记录；不改immutable原图，不新增Host调用。W10负责同fixture的20分钟heap最终验收，不能把首轮不达标改成更宽门槛。

使用工作台摘要与按页详情，不在前端自行判断质量pass。图层切换保持page_id，历史比较固定version。viewport/selection是UI状态，不写Document；缺图动作可定位已有待办，不轮询触发continue。

## 源码入口

`resources/static/v2/` 画廊、矩阵、图像容器与selection模块（新增提案）；`view.py`摘要由W01维护；`web.py:205`文件引用读取。浏览器合成24/30页fixtures独立于生产runs。
