## 契约与服务复用

按DX-SPEC§4/§7新增requests freeze/show、attempts show及task call begin/settle的请求/尝试绑定参数；均为待实现提案，复用现有call allocate/begin/settle与task accept，GenerationRequest/Attempt不得另建调用账。冻结由核心返回request_id/input_hash，按models.canonical_json_bytes的UTF-8、ensure_ascii=False、sort_keys=True、紧凑分隔、allow_nan=False序列化后SHA256，无尾换行；覆盖完整input且排除自身hash/事后ID/时间戳/Attempt，Host不自行归一或指定可信hash。任务声明protocol_version/required_capabilities，start声明supported_protocols/capabilities；调用前校验，不凭Host名字推定，旧任务保留旧规则。新旧UI/core/Host/reader/writer组合显式兼容，旧格式不原地迁移。Host经deck-master CLI共享Service写入，HTTP写仅供同源浏览器session；能力/错误扩展不改变现有退出码0/2/3/4/5。

扩展 Document 对 ContentPlan 的引用；ContentPlan 至少含版本、输入摘要、章节ID、页目标ID、source/version/locator、未解决事实；Page保持正文唯一真相。GenerationRequest 只冻结调用前输入：Page/design/template、拟提交确切文本、reference asset role、请求参数与基准；不包含事后 call_id/usage/output。Attempt 追加记录实际 submitted 文本/附件/参数及 task、call allowance、execution/invocation、用量和结果ref；一请求可多尝试。实际提交与冻结文本有差异时显示差异及原因，不修改冻结请求。旧 schema/version 明确缺字段兼容；新 Host 协议缺必需真实请求时拒绝采用并保留调用事实。证据字段 `evidence.observer` 区分 `core_frozen|host_reported|tool_observed|provider_receipt`，同时记录证据引用与采集者：core_frozen仅证明核心冻结了拟用输入，不证明已发送；host_reported是Host申报，不是独立观察；tool_observed是实际工具调用/返回的可核对记录；provider_receipt是供应商真实回执，没有则不填。证据级别由真实采集路径与引用校验决定，不能只接收Host自行填写的更高标签。图像内容、prompt相似或Host总结均不能作为独立提交证明。复用 project_prompt、open_blueprint_task、call_begin/settle、accept_result。

## 失败与恢复

调用前冻结失败则不派发外部调用；调用成功而回传失败保留未采用状态，允许按同operation_id补报同一结果。历史缺字段读降级；缺独立提交证据时显示“Host申报”而不是“已验证”，强语义入口暂不启用。禁止原地猜测填充或删除旧对象。

## 独立交付与回退
