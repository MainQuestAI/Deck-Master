## 契约与服务复用

工程约束见 [ENGINEERING-SPEC](../ENGINEERING-SPEC.md) §3–§5：候选生成依据和采用计划分开；项目侧draft journal为草稿恢复主副本，浏览器只临时缓冲，按ETag/sequence保存；项目ACK、仅本机未同步、结果未知必须区分。未ACK不能宣称自动跨origin，提供恢复文件显式下载/导入；历史restore不回滚个人journal。真实文本选段采用原始UTF-8文本的Unicode code point左闭右开范围及excerpt验证；SVG仅安全img+可验证稳定ID静态几何映射，不可映射用rect，不造OCR或iframe脚本bridge。

SVG/PPT详情新增“制作与可编辑性”摘要，复用已存artifact.editability、PPT render_report的text_runs/native_shapes/发现、object_trace及professional_use/desktop_editing记录。计数各自标来源/快照；text_runs不是可编辑文本框数，native_shapes也不是非文本图形数。若从SVG trace计算image元素数，必须标“SVG输入图像元素（推导）”，不写成PPT光栅化比例；未计算或无记录显示未知。字体只区分声明字体/声明fallback与实际诊断匹配，不把fallback列表当已成功替换。详情显示形状和文本可编辑的能力边界，不承诺Office Edit Data、原生表格、浏览器直接改PPT。当前代码没有OCR或图像文字叠加选取层；图片用点/框意见，文本范围只用于真实正文/prompt文本对象。专业质量及桌面实际编辑未经记录时均显示未评估。

读取W01 lineage及W02请求/attempt事实；PromptDraft单独保存，指向base request/content hash，不写旧submitted。可用确切text ranges定位；自动诊断只标推测。复用Page visible_atoms、文件隔离渲染，返回来源工作区时固定材料版本。

## 行为验收

- **W05-AC01**：从原图最多3次明确点击找到对应逐页稿及提交记录；evidence.observer为host_reported时写“Host申报”，仅可核实证据支持的实际提交使用强语义；不可得时找到未记录说明。
- **W05-AC02**：prepared、actual、草稿同时存在时文案、只读/可编辑和版本明确；显示core_frozen/host_reported/tool_observed/provider_receipt含义，冻结不等于提交、申报不等于独立验证；改草稿不改原图/历史。
- **W05-AC03**：按UI-SPEC§3/6固定页/层/版本，同页比较的新结果不替换对象；候选画面主栏是当前采用与所选候选，参考图辅助呈现，候选切换连同依据/按钮目标一起切；单页SVG预览不冒充assemble后按页PPT预览。
- **W05-AC04**：模型/参数/参考图未知时显示未知；不能由项目默认值填成当时实参。
- **W05-AC05**：老prompt不能可靠分段保留全文/选段，建议标推测并供原文核对；文本选段复用ENGINEERING-SPEC§5原始Unicode code point范围，不归一CRLF/组合字、不直接用JS UTF-16 offset，不把图片伪造成文本层。
- **W05-AC06**：草稿分未保存/仅origin缓冲/项目保存中/已ACK/待核实；项目journal为恢复主副本，ETag冲突保留双方。只有ACK草稿自动跨端口恢复；离线未同步提供下载恢复文件及新origin显式导入，校验项目/基准/hash不自动提交。配额/服务失败不报已保存，pending payload与后写draft分离。
- **W05-AC07**：缺图/仅正文/历史/失败均有下一动作；SVG/PPT摘要按证据显示editability、text_runs/native_shapes、字体与专业/桌面编辑评估。无raster计数或OCR文字层不补造；SVG推导image数明确标来源，未经实际桌面编辑不写已验证。

所有编号只有本卡为最终验收 owner。自动化、浏览器、真实 Host 与用户验收分别记录；未执行项保持未验证。
