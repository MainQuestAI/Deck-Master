## 1. 架构

核心保存事实，Web投影及前端呈现，Host做语义和生成。采用新图和正文编辑都必须在现有事务边界内推进版本；前端不能自行把旧PPT改成有效。7类名称是数据职责，不要求7个新服务，ArtifactEdge先从已有引用投影，避免双重关系真相。

```text
浏览器/CLI -> 本地service -> Store(对象+revision+operation)
                 |               |
                 +-> Task/交接 -> Host -> 工具/模型
                 |                         |
                 +<- 校验结果/Attempt <----+
                 +-> compile/check/export -> 不可变成品
        只读view/summary -> 矩阵/画廊/单页
```

10倍/100倍压力首先来自大图解码、历史全量读取，不是数据库池（此产品无数据库池）。按页/层延迟详情和摘要缓存足够解决本期30页，100页只做边界观测；不为100倍建设分布式服务。单点是本地服务/磁盘，重开后从持久化事实恢复。

## 2. Error & Rescue Registry

下面是提议错误码类别，沿用现有异常类型可表达时不新增重复类。每条由所属W卡在实现时落实，不把catch-all当安全兜底。

| 入口/失败 | 类别 | 救援 | 用户看到 | 验证owner |
|---|---|---|---|---|
| registry打开缺目录/旧格式 | ProjectUnavailable/legacy_run_format | 保留注册项、只读说明，不初始化覆盖 | 重选位置/用原工具打开 | W03 |
| lineage对象缺失/不可读 | MissingObject/ModelError | 该对象局部失败，其余可读 | 未记录/文件损坏+对象类型 | W01 |
| commit基准改变 | ConflictError | 不写，保留两份，重规划 | 具体变化页和重试入口 | W06 |
| operation同ID不同payload | OperationMismatch | 拒绝；同payload查原结果 | 已处理/请求内容不同 | W06 |
| 保存请求断线结果未知 | TransportUnknown | 核实原operation，不换ID盲重发 | 保存结果待确认 | W06/W10 |
| Host拒绝/空/无效结果 | Refused/EmptyResult/EnvelopeError | 保留原当前稿，记录失败及缺字段 | 未产出候选/修正输入 | W02/W07 |
| 取消、删页后晚到 | Cancelled/Superseded | 拒绝采用，调用事实留存 | 结果未采用及原因 | W07 |
| 磁盘满/写权限 | OSError具体errno | 原子事务不发布，清本次暂存 | 保存失败、可重试 | W02/W06 |
| 工具缺失/交付检查阻断 | needs_tool/ReadinessBlocked | 不造输出，定位前置 | 缺工具/缺检查与操作 | W11 |
| 导出中断 | ExportFailure | 固定快照，临时文件不当成完整下载 | 未完成，重试原版本 | W11 |

## 3. 安全

实际扩大的面是本地项目注册、正文/提示词、SVG预览和文件下载。必须把注册目录权限与项目会话绑定；任意origin不能注册/读取本地目录，路径参数不能绕出对象根。SVG以隔离图像或受限sandbox呈现，文本不经innerHTML直插；材料中的指令是数据，不能授权主机操作。没有新增云账号、密钥或执行代理，风险主要在本地越权与对外包泄露，威胁中等概率/高影响，需W03/W11验证。

## 4. 数据与交互边界

```text
输入 -> scope/type/size校验 -> 冻结计划/基准 -> 原子写 -> 任务/候选/采用投影
 nil/未知 -> 不伪造事实     empty -> 拒空修改/保留合法空项目
 错类型/超限 -> 定位错误   冲突/重复 -> 对象级说明/同ID查询
 超时 -> 结果未知核实      部分返回 -> 按page/attempt显示，不换当前
```

```text
编辑A              候选采用B          共享当前
读取R1                                R1
                  校验并采用 ->        R2
提交基准R1 -------------------------> 冲突/按明示兼容规则处理

候选B             编辑A              共享当前
读取R1                                R1
                  保存正文 ->          R2
采用基准R1 -------------------------> 冲突，B仍可看不可覆盖
```

所有共享当前指针的检查必须在同一锁/提交边界重验，单独的preview检查不保证安全。双击、换页、后退、筛选外选择、零页、大列表、结果倒序、断线重放8类必须在卡验收；UI草稿不被轮询覆盖。

## 5. 代码质量

新前端模块按工作对象/能力拆分，用共享页选择、快照和草稿键；不把新流程继续塞入旧app.js。业务规则留在核心，HTTP与CLI共享同一服务，不在两个调用端分别实现采用/失效。复用原子存储和幂等而不是另造任务引擎；新增对象以可版本化数据定义为先。

## 6. 测试

```text
真实来源缺失/历史 ---> core W01/W02 -> HTTP固定revision -> browser同层画廊
标注/草稿 -------> core W06校验/原子 -> browser坐标/刷新/冲突

```

关键回归拒绝错误：未改页hash必须完全相等；取消先后两种顺序不得覆盖；重排不能串意见；缺prompt不得显示真实；导出后台变化不改变固定内容。核心多、接口适量、浏览器用代表场景，真实Host单独证据，避免大量脆弱截图断言。模拟时间驱动轮询/超时测试，真实外部生成不进入普通CI；质量评估使用授权样本和明示维度而非强制像素一致。

## 7. 性能

最慢路径是原图解码、历史关联展开与PPT导出。计划已要求30页摘要不带所有base64、单页prompt按需；补实际payload/解码图数/内存记录，以观测而非伪造p99。<1秒是预热本地服务目标，首次Host工具启动与PPT制作另计；并发轮询仅一请求在途，长导出不阻塞阅读。

## 8. 观测与排错

按operation_id、request_id、attempt_id、task_id、page_id和revision串起日志，在操作入口/拒绝/发布/取消分支记录码与耗时。用户运行台展示等待Host、工具失败、结果被拒的实际原因；不能只写“出了点问题”。产品指标包括返工层分布、等待时间、调用/重建次数与导出阻断，不上传客户内容做遥测；本地诊断包必须可剔除材料和密钥。

## 9. 发布与回退

```text
基线核查 -> 核心向后可读/写版本门槛 -> /v2/显式入口 -> 隔离安装验证 -> 授权默认切换
失败 -> 关v2新写入口 -> 旧UI读现有可支持格式 -> 新格式用新版只读/工程包恢复
                                           禁止旧写端降级改坏新字段
```

不存在数据库在线迁移，本地协议升级同样需要旧写端检测。最新代码重打wheel/sdist后验证资源和Skill，不能拿旧候选说明新代码；初始5分钟看启动/静态资源/旧项目只读，首轮完整执行看请求与结果关系，切换默认入口另走发布授权。回退界面不等于逆迁移项目数据。

## 10. 长期方向

可逆性4/5：导航和前端可替换，持久化请求/采用事实一旦写入要长期兼容。主要债务是旧项目缺失来源与Host能观察的边界，不应通过自动猜测抹去；UI明确未知允许渐进演进。保持固定快照、显式因果和同一核心，比绑定某一模型的prompt拼接规则更耐用。

## 11. 产品设计

首屏先回答项目是什么、当前能看什么、需我做什么，再显示页×阶段矩阵。图像多时画廊是主动作；没有产物时显示内容摘要和交接；历史/候选有持续标识，真实状态选择下一步。核心流程是“看全稿→查一页→限定范围→试一页→比较→采用→继续”，原型需从陌生用户角度走而非开发者找按钮。

| 功能 | Loading | Empty | Error | Success | Partial |
|---|---|---|---|---|---|
| 项目/内容 | 已知名称+骨架 | 建/开项目或选材料 | 路径/格式说明 | 目标/材料/正文 | 已提取与未读分开 |
| 画廊/链路 | 保留比例 | 保留缺图页 | 单格失败可重试 | 同层产物 | 已有/缺失/失效并存 |
| 风格/试作 | 不造运行 | 先选参考目标 | 冲突/Host拒绝 | 候选可比较 | 返回页独立可读 |
| 交付 | 固定版处理中 | 无产物列前置 | 检查缺口 | 指定版文件 | 审阅有缺项说明 |

DESIGN保留冷墨/琥珀、字体与克制工具风格，替换审阅台定位。1280/1440桌面、键盘替代框选、对比度和恢复焦点进入设计与浏览器复核；手机仅阅读不假装全编辑。没有新增装饰性大指标卡。

## 对象状态与错误分支补图

```text
ContentPlan/Page: 草稿 -> 保存版本 -> 当前/历史；合并拆分新ID -> 原页历史
Request: prepared -> frozen(不可变) -> Attempt引用；submitted由Attempt观察事实，不改输入
Attempt: 待接手 -> 已接手 -> 已提交 -> 返回/失败；取消可发生各等待阶段，晚到仅记事实
ChangeSet: draft -> planned -> committed -> tasks；planned过期 -> 冲突 -> 新plan
Candidate: 试作返回 -> 待选择 -> adopted/discarded；基准变化 -> 不可直接采用
StyleRecipe: 建议 -> 用户保存版本 -> 冻结引用；编辑生成新版本
ArtifactEdge: 只读投影；已有/推导/未知不是完成状态

校验失败 -> 对象旁定位错误 -> 保留输入
提交断线 -> operation查询 -> 已应用返回同结果 / 未应用同ID重放 / 冲突保留双方
晚到结果 -> 记录Attempt -> 检查取消/基准 -> 拒绝覆盖 -> 当前指针不变
```
