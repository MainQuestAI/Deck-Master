# 生成工作台：画面与交互规格

本文件与 PLAN.md 一起构成 v3 设计基线。原型是合成数据演示，正式能力的验收归属见 W01–W12。

## 1. 首次进入与回来

全局入口不强迫用户先开聊天。每次进入先解释“这是什么项目、现在能看什么、下一步谁来做”。项目内顶栏持续显示项目、版本和待办入口；内部任务数量不等于待办数量。

| 情境 | 落点 | 首要动作 | 保留的背景 |
|---|---|---|---|
| 没有注册项目 | 项目启动页 | 新建项目 / 选择项目文件夹 | 一句话说明用于看整稿、追溯生成、控制局部修改 |
| 新项目尚无内容 | 内容与来源 | 选入材料并交接内容整理 | 用途、受众与材料状态 |
| 首次打开且已有原图 | 制作总览 | 看整稿原图 | 可看页数、需用户处理的具体事项；不自动强迫校准 |
| 有上次阅读位置 | 恢复页面、层、缩放和版本 | 继续阅读 | 待办数量可见；基准过旧提示但不强制跳走 |
| 通过通知或待办进入 | 定位该意见、交接或候选 | 完成此项所需的动作 | 返回原工作面的入口 |
| 项目不可用、被移动或旧格式 | 保留该项目条目的启动页 | 重新选择位置 / 查看兼容说明 | 不删除历史条目，不自行遍历磁盘寻找 |

同一画面只有一个高权重主按钮。总览首次进入以“看整稿原图”为主；待办项使用次级按钮。用户进入具体待办后，该项动作才成为主按钮。不能让“看整稿”和“先改风格”同时争主次。

```text
项目 / 当前版本 / 待办 / 返回位置
├─ 导航：总览 · 内容与来源 · 整稿画廊 · 风格校准 · 运行与交付
└─ 工作面
   ├─ 当前对象与一句话任务 → 唯一主动作
   ├─ 主要内容：整稿图件 / 正文 / 比较画面
   └─ 需要时展开：依据 / 精细设置 / 运行记录
```

矩阵是进度索引：默认只显示阶段短状态和小缩略图，时间、请求身份、失效链放详情。矩阵状态“可看”不写成“质量通过”。初始只展开有关注项的章节，其余章节可折叠但总页数明确。

## 2. 新建与打开项目

新建表单有可见标签：项目名称（必填）、用途与受众（必填）、页数目标（可选）、材料列表（可暂空但不能宣称内容可生成）、保存位置（必填）。按“创建项目”建立项目，可沿现有create登记唯一待交接compose，但不执行模型。信息不足时先补材料/要求；补充沿inputs协调与旧任务失效规则。点击“整理内容并生成大纲”读取并交接最新eligible compose，不无条件再创建同一任务，先显示交接面板。

打开项目用“选择项目文件夹”。本地服务调用受控的本机目录选择器；不支持选择器的环境提供可见的路径输入替代，输入后服务验证格式与访问权限。浏览器上传的文件名称不当作目录路径。取消选择不改变当前项目；无效、无权限、旧格式分别在位置字段旁解释；不存在的目录仅新建流程允许在选定父目录下创建。最近项目按显式注册保留，移除条目只取消注册、不删除项目。

原型只展示表单和样本打开，不模拟真实目录权限，也不把样本表单称为创建了真实项目。

## 3. 整稿观看与单页链路

整稿画廊首先显示原图联系表，页号、标题、真实层类型、当前适用性置于图件下方。缺图保留同尺寸空位与下一动作。三列默认，提供两/三/四列与连续模式。对齐16:9画布，完整显示，禁止裁剪填满。

选中2–4页后出现固定选择条：“比较 N 页”“设为参考”“加入目标”；筛选外选择显示数量，并可一键清除。点图进入单页。单页标签依次为来源、逐页稿、提示词、原图、SVG、PPT；标签反映缺失而不补造。

单页第一层回答“我看的是第几页、哪一层、哪一版”；第二层是内容；第三层是生成依据和动作。原图右侧可打开“当次生成依据”，默认摘要：绑定请求、当次实际文本、参考图、证据来源。内部 ID 可复制但不要求人理解。未记录时明确“这张图的实际提示词未记录”，提供预备稿入口并保持不同标题。

## 4. 风格校准默认操作

默认只要求四件事：选固定参考原图、选目标页、写一句要求、点击“先试1页”。持续展示“保留目标页标题、事实与数字”。实际提示词未知时仍可按图片参考试作，依据写“参考图片”，不假称复用了历史提示词。

“精细设置”默认折叠，含色板、字体层级、密度、线条、构图、参考角色、模型参数与 prompt 差异。用户需要精确控制时主动展开；检测到互斥约束、目标事实可能被替换或基准变化时，系统展开相应问题并要求明确处理，不能静默猜测。

以下“当前稿保持”指试作自身不替换当前采用；既有自动生产可独立推进。此时保留原固定比較，提示当前稿已更新并重新计划采用，不设置页级hold或暂停整项目。无并发样本中当前稿会保持。

先试前显示短影响条：“第8页产生一个原图候选；当前原图和PPT继续可看。采用后第8页SVG及整稿PPT需更新。”详细依赖可展开。调用上限按已冻结请求内的真实数量展示；未知费用不估价。

## 5. 持久交接面板

“先试1页”保存请求后进入同一持久面板；离开页面不丢失，从项目待办与运行列表都能返回。面板固定目标、产物层、已保存要求与当前下一步。

| 状态 | 用户看见 | 主动作 |
|---|---|---|
| 保存中 | 正在保存请求；保留输入 | 暂停重复提交 |
| 保存结果待核实 | 结果尚未确认，当前要求仍在本机 | 核实保存结果（原 operation_id） |
| 待交接 | 要求已保存，尚未开始；接下来交给 Codex | 复制交接说明 |
| 已复制、未接手 | 已复制，尚未开始；在 Codex 发送这段要求后等待接手 | 再次复制；可用时次动作“在 Codex 中打开”仅预填 |
| 已接手/处理中 | 真实接手时间、已完成项、仍在处理项 | 查看详情；取消为次动作 |
| 部分返回 | 按页显示可比较/仍运行/失败 | 查看已返回候选；不说整组已完成 |
| 超时 | 30分钟无完成结果，执行状态尚待核实 | 核实状态；次动作取消；取消成功才可新交接 |
| 返回候选 | 哪些页有候选，旧采用仍保留 | 比较候选 |
| 失败/取消 | 已保留的要求和结果事实，具体失败原因 | 调整后重新计划；取消后晚到结果不覆盖 |

时间达到阈值不自动判定失败、不自动重发外部调用。无 Host 时仍保存为待交接。服务断线提示最后同步时间，不清空已读内容。

## 6. 候选决策画面

```text
第8页 · 原图候选 · 基准R18              [当前待决定]
当前采用（固定R18）      | 候选（请求Q2 / 尝试A1）
完整原图                | 完整候选图
事实/数字检查提示        | 实际生成依据（可展开）
参考第7页（辅助缩略图，可放大）
候选缩略条 A1 / A2 …     [采用这个候选] [保留当前] [再试]
```

两主栏是当前采用与选中候选；参考页作为辅助，不挤掉判断前后变化所需的位置。标题持续显示固定基准、请求/尝试和生成时间。切换候选切换其依据和采用按钮目标；不可拼接不同候选的图与prompt。

生成中显示原采用与等待位；失败显示具体失败与保留当前；已采用标明采用版本；基准变更时仍可比较原固定双方，但禁用直接采用并说明新基准差异，提供重新计划。批量结果逐页列出候选/失败/未返回，让用户勾选采用集合；提交时整组全部成功或零采用。冲突时明确“本次未采用任何页”，保留选择，用户排除冲突项后新操作重新计划。

## 7. 标注、草稿与冲突

默认阅读模式：拖动不创建意见。工具条明确“整页意见 / 点标注 / 框选 / 文本意见”，按层开放适用工具；拖动框选、释放确认范围，Esc取消尚未保存范围。框可以选中后删除或重画；缩放/平移模式与标注互斥。右栏持续显示绑定的页、层、版本和区域数，按“保存意见”只保存，再按“加入修改计划”才进入影响预览。

已保存意见以编号标记定位原区域；点击意见回到其原产物版本。文本意见保存原文摘录及文本版本；新版不自动迁移范围。无鼠标用户可对整页写意见，也可通过百分比 x/y/w/h 字段设置区域；错误字段就地说明并保持内容。

草稿状态条区分未保存、保存中、已保存、保存结果待核实。任何网络异常不清掉输入；保存结果未知时可以继续写本机草稿，但暂停新的服务端提交，先用原 operation_id 查原请求。后写草稿与待核实payload分别保存，避免重试变成异内容复用ID。

冲突面板两栏显示“你的本机草稿 / 服务端新基准”，保留双方，可复制、导出文本或基于新基准建立新草稿；不自动用最新覆盖本地、不用旧基准强写。浏览器存储配额/不可用时直接提示并提供下载草稿，不能显示已持久保存。

## 8. 全功能状态表

| 功能 | 加载 | 空 | 错误 | 成功 | 部分 |
|---|---|---|---|---|---|
| 项目入口 | 条目骨架 | 新建/打开项目 | 目录错误在条目旁 | 可进入并说明可看产物 | 某目录失联，其他仍可开 |
| 内容与来源 | 保留当前文本+读取标识 | 选入材料/补用途 | 标明失败材料，保留稿 | 来源与页关联可追踪 | 已上传、未读取分开显示 |
| 总览矩阵 | 固定行列骨架 | 无页则到大纲 | 项目断线保留最后同步版 | 点击进入真实层 | 各页独立状态，不画假完成率 |
| 画廊 | 缩略图同尺寸骨架 | 当前层未生成→定位生成要求 | 单图失败可重载 | 完整联系表/连续/并排 | 缺图保留位置，不替代层 |
| 提示词台 | 显示版本、载入依据 | 未记录→查看预备稿 | 绑定读取失败且不退回最新 | 当次请求与观察来源 | 只有Host报告时照实标记 |
| 标注/保存 | 本地输入保持 | 选择范围/整页意见 | 未保存或结果待核实 | 已保存且可定位 | 多区域仍是独立目标 |
| 交接/执行 | 保存中/真实处理中 | 没有待执行要求 | 可核实/取消/重计划 | 返回候选或正文已更新 | 按页展示完成顺序 |
| 候选 | 保留当前，候选等待 | 尚无候选→查看运行 | 失败/冲突就地说明 | 明确当前候选采用结果 | 可用项选择集合，原子采用 |
| 历史/导出 | 固定版本后准备文件 | 无文件说明缺项 | 保留版本与具体拒绝维度 | 下载文件及版本清单 | 审阅可含未完成说明；交付仍校验 |

## 9. 使用节奏、响应式与无障碍

| 时点/动作 | 用户希望感受 | 设计支持 |
|---|---|---|
| 5秒：打开 | 知道这是什么、我该看哪里 | 项目+可看层+一个主动作 |
| 1分钟：浏览整稿 | 能看出节奏、异常页 | 同层联系表、连续阅读、筛选 |
| 5分钟：纠偏 | 选择范围可控，内容不会乱换 | 参考图+一句要求、影响预览、先试一页 |
| 等待：离开再回来 | 无需记住复制了什么 | 持久交接、真实接手事实、恢复位置 |
| 比较采用 | 有依据地选结果 | 固定版本、真实请求、多候选身份、局部失效 |
| 长期使用 | 以前的选择可追溯 | 共享核心事实、历史可看、明确未知与兼容 |

1440×900左栏208px、顶栏56–64px、上下文340px；1280×800左栏可收至64px，右栏改可收合面板，阅读内容不缩字。1024–1279默认单页阅读和待办，关闭多页校准的并排工作面并说明桌面要求；窄于768保留项目、阅读、意见列表，不声称完整编辑体验。原型窄屏布局仅作预览。

界面标签14px，正文/提示词阅读16px，非正文元信息至少12px且对比>=4.5:1；低对比 faint 仅装饰/禁用，不承载必要说明。主要动作和图标命中区>=44×44px。所有操作有可见focus；对话框有标题、圈定焦点、Esc关闭并返回触发点；程序状态用aria-live简报，长表格采用语义table或有明确键盘规约的grid，不将百余单元格全部放入普通Tab序列。Tab进入表格一次，方向键移动，Enter开层，Esc回原焦点。图片提供页号+标题+层+状态替代文本。减少动画模式禁用移动过渡，任何内容不靠动画才能出现。

深色选择来自长时间阅图时减少界面与图件竞争的既定方向；不引入发光装饰。正式字体离线随包及许可检查是W12硬验收，原型的系统中文回退明确标注。


## 10. 内容与整稿操作的具体画面

正文层提供“编辑正文”：标题、可编辑文本/列表/表格按真实结构显示，保持页号/稳定身份和基准可见。只有正文的项目默认进入该层，不造缩略图。进入编辑保留阅读位置；“保存正文”只保存，不请求生图。保存中防重复，成功显示新版本与受影响下游；刷新/切页不串稿。错误、未知保存和冲突进入§7的同一套输入保护，不新增恢复机制。

内容与来源顶部的“调整任务要求”编辑用途、受众和已有决定；材料区选择补充、替换或移除。先显示本次差异和保存范围，再交接影响判断；已提供事实默认保留，不反复询问。Host返回受影响页、无影响理由和保留的决定；用户据此查看局部稿，不默认重制整套。仅有上传记录不能显示已读或已用于成稿。

整稿列表提供拖动和“上移/下移”按钮，按钮可键盘操作，排序后焦点与选择跟随page_id。移除确认列出页面标题、历史保留、相关未完任务和整稿文件影响；确认后定位相邻页，可从历史查看移除页。多选后的动作条显示选定页数与固定基准，提供“跨页改写/合并/拆分”。保存请求进入同一交接面板；只改写保留页身份，合并/拆分候选展示新身份与来源关系，旧意见不自动迁移。采用前查看影响，采用后新页进入待制作；未选页保持。

## 11. 历史查看和恢复

从运行与交付进入版本列表，默认只读，持续显示“历史版本R… / 当前版本R…”。先查看或固定比较，再启用“恢复为新版本”。确认面板列源版本、当前版本、内容/页序/产物变化和受影响运行任务，说明调用事实与取消记录不回滚。取消不写入；确认后提交带当前CAS的操作并产生新版本，回到恢复后的当前稿。若当前稿已变化，保留比较双方并重新计划；不把历史指针直接写回current。恢复完成仅代表新版本已建立，不代表成品或专业质量通过。
