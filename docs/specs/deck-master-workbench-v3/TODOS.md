# 明确延后项

本期保留完整生成工作台。以下是新增方向，不是遗漏的已承诺功能。

| 项 | 为什么延后 | 触发条件/前置 |
|---|---|---|
| 先生成全稿原图、后统一转SVG的调度政策 | 会改变既有逐页门控；与显示全稿不是同一变更 | M2真实往返后，单独评估核心调度与专业复核 |
| 自动风格一致性评分 | 当前用户需要可见比较和可控修订；机器分数不能替代目标判断 | 有代表性项目和标注基线后独立验证 |
| 多Host自动连接/远程协作 | 本期复用本地Host交接；不引入账号/执行器 | 稳定完成本地单用户流程后再定义授权与调度 |

自由画布PPT编辑、外部PPT自动回写、通用节点编排与插件市场是明确不做项，不作为隐含待办。

## 未采用历史产物的显式回收（新增后续方向）

要解决多轮原图候选占用磁盘的问题；收益是释放未采用的大图空间，代价是历史可重放性与引用完整性复杂化。当前不可变对象仍保留，“放弃候选”只改变选择状态，不删除blob。后续必须先定义哪些引用仍被历史/当前/导出使用、用户如何确认删除、清理墓碑与hash如何显示；只可在W07/W11版本规则稳定后单独设计。不能借此对现有项目自动GC。
