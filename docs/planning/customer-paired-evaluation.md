## 判定与交付

按既有公式逐 case 先聚合两次运行，再计算总体：用户主动时间比值中位数 ≤0.70；候选各 case 首稿可保留页 ≥70% 且无关键遗漏；六维总体提升 ≥0.5/5。基线总体 ≥4.3 时采用既定天花板规则，任一个案下降不得超过0.25/5且不能有关键缺陷。完整规则以链接规格为准，不在看到结果后改阈值。

预算差异、external_failure、baseline_blocked、缺评分、缺材料和未完成运行均保留。样本或独立评审不足时报告 outcome_pending / exploratory，不能标 accepted。最终文件必须具备当前质量门和真实用户批准。

交付给用户：十二次运行与全部重试索引、冻结首稿/最终稿身份、主动投入记录、双人评分、逐 case 差异、失败原因和明确结论。原始客户材料、图片、录像与日志留本地；仓库仅提交脱敏案例 ID、摘要、哈希和安全引用。未经明确授权不发送邀请、不共享材料、不发布结果。
