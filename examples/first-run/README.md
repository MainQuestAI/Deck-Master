# First deck / 第一份方案

This self-contained sample proposes an inventory pilot for the fictional Cloudsprig Tea chain. All names and numbers are invented. Each language has source material and a brief: [English material](en/material.md), [English brief](en/brief.md), [Chinese material](zh/material.md), [Chinese brief](zh/brief.md).

After [installation](../../README.md#install), open Codex at the repository root and type:

> Make a 6-page deck from examples/first-run/en/material.md following examples/first-run/en/brief.md, in ./first-deck.

Run `deck serve ./first-deck` to view the draft; it binds `127.0.0.1` and prints the URL.
