# E06｜输入材料

**性质：虚构教学材料。仅用于说明方法，不是客户项目事实。**


## 来路与范围
来自Gemini案例三，改写过度确定的技术结论。所有合同、日志与数值均为虚构教学材料，不是真实事故或法律结论。
受众已会调用向量检索与模型接口，目标是识别分块导致的上下文缺失，并设计可验证的改进，而不是学习某一种算法必胜。
给定条款：14.1 交货延迟超过5个工作日，按日支付合同总额0.5%违约金；14.4 上述规定在法定不可抗力（含十级以上台风、地震）且48小时内提供气象证明时免除适用。其他条款、法律及具体证明情况均未知。
给定切分：500字符、50重叠；14.1在块42，14.4在块44，相距约680字。某虚构检索记录只返回42，44相似度0.51、未入Top5。该数值不代表通用效果，也没有改进后的实测值。
材料描述有人改成较长块或语义切分仍遇问题，但没有可复现模型、数据集与评测记录。不能据此宣称长块必然失败、语义切分无效或只有父子索引能解决。
