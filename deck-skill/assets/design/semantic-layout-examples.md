# 三种内容关系的设计示范

## 对比：共同基线不能被隐藏
取E02的A/B/C。三列按同一费用口径和可用时间比较；C首阶段19万元和全部30万元应在同一层级清楚标出。不能只把19万元和B的28万元并排，掩盖能力范围不同。必要时总览一页，验证与追加条件另页。

## 机制：观察与假设箭头不是同一种关系
取E04的“同步变化→开户→使用→续约”。将材料描述的开户困难与待验证的续约作用区分；不要在箭头上放未给出的效果数。月活28%只挂在月活指标上，不挂到“开户失败72%”。

## 教学：对照必须让关键差异可见
取E03的两条政策回答。并排呈现登记时间、适用范围和答案要求，突出决定适用性的日期；其他视觉变量尽量一致。下一页给新题时可以重复规则，但不要复制整页解释。
