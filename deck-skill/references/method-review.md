# 方法审阅：审结论怎样成立，不数框架和字段

Review保持只读；提供具体findings与修改建议，实际修稿按既有职责交接。选中某张卡、返回了字节、画出问题树都不能证明模型已经正确应用。

## 阅读次序
先明确允许审查的对象与版本，再读源材料、正文、实际关系表达与必要方法。内容审阅不能只看标题；纯视觉范围不自动扩成商业方案重写。作者与审阅者的真实身份照实记录。

## 五个主要判断
观点是否回答真实受众问题；证据到判断间的理由是否成立；不同解释/方案是否被公平对待；页间与页内是否推进；受众是否能理解或使用。检查时定位原句、具体事实与影响，而不是只写“加强深度”。

## 任务、框架与反馈是否进入实稿
作者要表达的判断和争取的结果，是否实际改变了开场、展开深度、取舍和收束？框架分组能否展开到具体业务对象、动作、角色、交接与能力边界，而不只是更换栏目名称？专家意见是否改变了相关主张、正文或讲稿，事实修正与专业判断是否各守其身份？逐处对照原稿与改稿，说明保留理由；任务变化要读全文，明确只改一页或讲稿时也核对范围是否守住。意见处理状态不能替代对实际内容的阅读，这些问题不构成保存或导出的资格。

## 对不同主张用不同检验
事实描述检查来源与口径；算术检查输入与公式；解释检查竞争可能和条件；设计检查假设与作用关系；预测检查参数与不确定性；建议检查目标、真实替代和代价。不要把所有判断都要求做因果实验，也不要把附了链接视作充分证明。能力或机制说明未承诺收益时，不因没有测量方案而判失败；效果、收益和投资主张则核对其证据、条件及未验证范围。内部追溯与作者核验过程不因真实就需要上屏；合法业务引用及影响理解的条件仍应保留。

查阅页、要求响应矩阵和逐行核对的对照表应保留查阅效率，不因是表格或放在封面就判失败。E02 类选项按同一范围、期限与费用口径比较，保留非推荐选项的真实优势，具体方法见 [M05](methods/M05-options-and-value.md)。合成案例和教学数字只作示范，不能成为当前项目事实；下方错归因示范与 C04 适用于 E04 类共现推断，不以算术正确替代因果依据。

## 审阅示范
原句：“41家缩席客户中38家使用旧AD，因此LDAP是唯一根因。”
具体问题：“这是受损样本中的共现比例，不是完整的旧AD/新AD风险比较；资料也未排除客户规模、部署成熟度等差异。应将唯一根因改为优先验证的机制线索，并说清下一观察如何区分解释。”
建议正文：“旧AD相关开户困难集中出现在缩席客户，适合作为本期优先排查路径；先核对升级前后开户、激活与续约记录，再决定恢复连接器的覆盖范围。”

## 内容、主视觉与成品

对照正文里的关系、该次 image 任务的 task.md、原图和最终 PPT。内容关系错，交内容；主视觉选错或提示词漏了关系，交设计；蓝图里关系还在，重建或编译丢了，交重建。之后只复审受影响的页。

已写明的阅读任务 `purpose` 或构图句 `layout` 是时间线、交接、状态流或闭环，导出或构图却仍以查阅表为主视觉时，记为选错主视觉，交设计。生图前先修构图句与正文的执行约束见 [page-writing](page-writing.md)；合理查阅表仍按上方 D10 口径保护。

原图判断附实际看过的图片及页／区域证据；缺图或没看原图，原图项记未执行。

最终 PPT 判断附实际成品、渲染页及对象／文字区域证据；没有成品或没看最终 PPT 的实际渲染，PPT 视觉项记未执行。两条判断的证据不能互相替代；原图观感不能证明 PPT 结构或可读性，回读也不能代替看图。Office 实际操作另按 Q3 记录。

重建结果按共享的 [对照原图验收](reconstruction.md#对照原图验收) 实际打开预览与原图，检查界面控件、旅程动作／场景、步骤节点及方向、分支、回流和阅读顺序，写清被说明文字、默认卡片或清单替代的对象。只证明文字覆盖、字符串齐全、对象计数、图片数或机械 findings 通过，未对照原图对象和关系时，记重建未完成，交回按原图还原。

## 三层 QA

三个判断相互独立，分别给结论、实际依据和尚未验证的范围，不能用一个 boolean 同时宣告通过。

- Q1 业务语义：核对事实、数字、限定、能力边界与实际画面中的对象、状态、方向、分支和责任。机械部分读 SVG／编译回读；专业语义要实际阅图。方法读过、对象存在或箭头数量正确都不能证明语义成立。
- Q2 视觉保真、可读性和专业完成度：比较原图与最终 PPT 的实际渲染，核对标题主次、核心图形、空间关系、色板、图像质感、密度、阅读顺序、文字溢出、图标风格及跨页节奏。局部 bbox／pixel diff 只作定位工具，不是唯一判断依据；字体抗锯齿或渲染环境差异不能直接当作业务失败。
- Q3 可编辑性与 Office 兼容：分别核对标题、正文、关键数字、主要图形、表格／图表的结构回读，以及在目标办公软件中修改、保存和重开。照片／插画可不原生编辑，但不能承载唯一的关键正文。未做真实办公软件操作，桌面项记未执行，并说明结构检查实际覆盖了什么。

回读 `status=pass` 不等于 Q1 专业语义、Q2 视觉或 Q3 Office／桌面编辑通过；现有 `visual_review` 与 `desktop_editing` 仍为 `not_evaluated`。自查记 `self_check`，换 Skill 入口仍是自查；只有实际由其他执行／模型或真人审阅时才分别记 `other_model`／`human`，没有执行就不声称真实独立评审。

## 机械发现与阅图定位

有 PPT／回读时，先读已有 findings，再对照正文、原图和 PPT 实际阅图。沿用发现中的页及适用的对象、节点、边或 atom 标识；未返回的字段不补造，回读没有的专业问题用具体描述，不编造 code。

- 错归因：按页、原句及对应来源定位，说明缺少哪种对照或竞争解释；沿用上方示范与 C04 的判断方法，不做自动关键词裁判。
- 反箭头、漏分支：沿用 `reversed_arrow`、`missing_edge`，并查看相关的 `missing_node`／`edge_not_connected`；实际阅图指出起终点、预期方向或缺失的分支区域。没有预期边时，这些机械边检查记未检查或依据不足，不能声称扫过全图；生产投影的 edges 仍为空，不从 layout 解析或发明边。
- 遮字或正文缺失：查看 `unreadable_text`、`hidden_or_tiny_text`、`missing_visible_atom`。这些发现只覆盖现有可检查的文字问题，不证明已检出全部遮挡；Host 仍须指出页和不可读的对象／文字区域。页级发现没有对象定位时，实际阅图后补充区域，未看则注明定位未执行。

## 缺陷分级

- `Critical`：错事实、错数字、错方向、漏关键分支、误导能力范围、不能打开、关键正文不可见。
- `Major`：高密度页退化成文字墙、主视觉与页面任务明显不符、关键关系要读完段落才能理解、严重视觉失真。
- `Minor`：局部位置、行距、图标风格、非关键装饰。

沿用问题、影响、建议和尚未验证维度的报告格式，每条补充分级、页及对象／区域（语义问题附原句）、参考依据和推荐返修动作。分级写在报告或作者要求保存的意见正文，不另建状态或审批步骤。

作者明确要求保存时用 `deck review add`，method 取 `self_check`、`other_model` 或 `human`，与真实身份一致。不改正文，不生图，不执行 `deck run adopt`。算式文件可用 `python -m deck_tools.case_numbers` 复算；通过只说明算式，不说明归因。
