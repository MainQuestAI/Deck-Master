# 作品级视觉系统

整套页面共用色板、字体、网格和图表语言，避免逐页追加风格提示后各画一套。先用 `deck get` 读取作品 style。新建作品带上默认色板，不写入具体字体；无品牌时由 Design 按 `deck doctor` 在已安装字体里选定后再写入（安装后优先用 Noto Sans CJK SC），有客户品牌规范时用 `deck put` 把色板、字体写入同一套字段，不另建风格对象。

## 承载映射

| 能力 | 承载位置 | 约定 |
| --- | --- | --- |
| 16:9 画布 | 现有 `style.canvas` | 默认 1280×720 px / 13.333×7.5 in，不改模型；已有作品按实际画布。 |
| 色板 | 现有 `style.palette` | `[0]` 主色 `#164267`，`[1]` 背景 `#F5F7FA`，`[2]` 强调色 `#D97706`。 |
| 字体栈 | 现有 `style.fonts` | 推荐 Noto Sans CJK SC（安装后优先用），但推荐不等于写入每个新项目。新建时 fonts 保持为空，由 Design 按 `deck doctor` 在已安装字体里选定后再写入。回退字体名只有实际写入 fonts 才会进入 task.md。 |
| 字体层级 | 共享参考，不新增字段 | 主标题、二级、正文、图表标签、注释、关键数字，见下文。 |
| 安全区、网格、栏距、内边距、密度与留白 | 共享参考，不新增字段 | 用共同对齐与间距组织页面，不把每页塞满。 |
| 表面 | 共享参考，不新增字段；颜色取 palette | 背景、面板、分隔、阴影和边界共用色板。 |
| 图表语言 | 共享参考，不新增字段 | 连线、箭头、节点、分支、回流、图例、重点提示；不是图种枚举，不替代构图句。 |
| 页角色密度 | 共享参考，不新增字段 | 封面低密度、机制页结构密、案例页图像密、查阅页文字密。 |
| 风格基调 | 共享参考，不新增字段 | 只在本参考中表达，不写进会导出的 purpose / layout。 |
| 图标与插画家族 | 归 D05，当前不做 | 人物、生活照、手机原型不是投标稿默认项；不引入图标库。 |

无品牌时，新建作品自动写入的色板为：

```json
{
  "palette": ["#164267", "#F5F7FA", "#D97706"]
}
```

字体不随新建写入。空的 `style.fonts` 保持原样，由 Design 按 `deck doctor` 在已安装字体里选定后再写入同一字段；安装后优先选用 Noto Sans CJK SC。有客户品牌规范时，把客户的色板和字体写入同一套现有字段。`put` 的 style 是完整单元，修改已有作品时保留其 canvas 与 assets。旧稿缺省仍为空，不会自动补写。字体层级、网格等共享参考不会自动成为 task.md 的新字段，也不授权 Host 另加风格前缀。

## 字体与层级

推荐中英文共用 Noto Sans CJK SC（安装后优先用）；写入前用 [commands.md](commands.md) 的 `deck doctor --fonts <字体名>` 确认已安装。确需中英回退时，可按使用顺序在 fonts 中写入实际选用的字体，例如中文 Noto Sans CJK SC、英文 Noto Sans；只在本参考中提到回退名，不会把它带进 task.md。

以下是默认画布下的起点，单位为逻辑 px；同一层级在整套页面保持一致。换算为可见字号时按 [SVG 子集](svg-subset.md) 的画布与 transform 公式计算，不另设转换常数。

| 层级 | 建议字号 | 用法 |
| --- | --- | --- |
| 主标题 | 40–48 | 承担本页判断，优先给完整标题留空间。 |
| 二级标题 | 28–32 | 标出分区职责，不与主标题等重。 |
| 正文 | 20–24 | 保留解释和业务条件，装不下先调整组织。 |
| 图表标签 | 18–20 | 贴近对应节点、线或数据，名称保持简短。 |
| 注释 | 16–18 | 放出处与辅助说明；影响结论的条件仍作正文。 |
| 关键数字 | 48–64 | 与单位、期间和适用范围一起呈现，不独占事实。 |

## 网格、表面与留白

默认画布左右安全区各 64 px、上下各 48 px，内容宽 1152 px。以 8 px 为基础间距，可用 12 栏网格、24 px 栏距对齐主区与旁列；容器内边距通常 24 px，紧凑明细可用 16 px。网格是对齐依据，不要求每页画满等宽卡片。标题、主图与补充区留出可辨的间隔，按阅读任务分配空间；装不下时先删重复、重组或提出拆页，不整体缩字挤满。

背景取 palette[1]，标题、正文和主结构取 palette[0]，重点取 palette[2]。面板沿用背景色，以间距、主色细边界或低透明度主色分区；分隔线弱于关系连线。默认不用阴影；确需层叠时用主色低透明度表达，SVG 做法遵守支持子集，不使用 filter。边界只划分真实分组，不给每句话套框。客户品牌替换色值后，沿用相同槽位职责并核对文字可读性，不在每页另造颜色。

## 图表语言与页面节奏

连线通常用主色、2–3 px，端点接到对应节点边界；箭头表达正文已经说明的业务方向。节点按职责分组并保留标签空间，不因并排就暗示同级。分支在分开处写出条件，互斥结果与并列动作区分；回流走节点外侧，明确回到哪个对象，不画装饰性闭环。箭头的 SVG 几何做法见 [SVG 子集](svg-subset.md)。

同一含义共用颜色与线形；需要区分时用紧邻的文字或图例说明，不能只靠颜色猜。强调色用于本页重点路径、结果或必要提示，仍保留正文限定，不把所有节点都强调。这里规定画法的一致性；具体谁连谁、方向、分区职责和拍扁会丢的事实仍由每页构图句决定。

封面低密度，集中主张与必要身份；机制页结构密，给节点、方向、分支和条件留空间；案例页图像密，让图像与证据共同承担解释；查阅页文字密，保留逐行核对和定位所需的表格。专业高密度不等于每页都是最高文字密度，整套作品应有阅读节奏。

## 风格基调与模型边界

基调是克制、清晰、层级明确，以业务关系组织模块。作者用「像字节 / 谷歌」表达偏好时，只在这里理解为对齐、模块感和层级的参考，不能代替本页结构，也不写进会导出的 purpose / layout。品牌规范明确时直接沿用，按实际需要做样页，不设八张样张确认硬门。

风格基调和字体层级目前只写在本参考中，不持久化到作品；以后确需持久化时另行改模型并定义迁移。
