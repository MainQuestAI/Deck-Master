# 按任务选择方法与案例

本文件教选择，不是新业务流程或授权入口。已有工作单和已确认稿件优先；仅通过当前版本支持的资源选择接口请求资源，已冻结 Task 不临时增添文件。

## 先识别本次需要完成的工作
读出受众已知、期望变化、输入材料的角色、现有决定和允许修改范围。把目标写为“理解什么／判断什么／选择什么／学会做什么”。不把所有任务改成预算审批。明确只改某页时，不重新组织整份 Deck。

## 找到真正缺少的认知动作
| 当前困难 | 首选方法 | 下一步可能需要 | 可读案例 |
|---|---|---|---|
| 主题泛，难以决定材料去留 | M01 | M02 或 M09 | E01 / E03 |
| 有大量指标但没有值得讲的判断 | M02 | M03、M04 | E01 / E04 |
| 数据与结论之间缺一句“为什么” | M03 | M04（仅因果主张） | E01 / E05 |
| 同一现象有多种可能解释 | M04 | M02、M06 | E04 |
| 推荐已写出，但没有公平的替代比较 | M05 | M03、M06 | E02 / E05 |
| 推荐对采用率、成本或未来条件敏感 | M06 | M05 | E02 |
| 事实都对，仍是资料拼接 | M07 | M08 | E01 / E02 |
| 每页成立，但全文没有推进 | M08 | M07、M10 | E02 / E04 |
| 培训只有定义，受众不会应用 | M09 | M03、M10 | E03 / E06 |
| 文稿重复、太长，或删短后失去解释 | M10 | page-writing | E01 / E03 |

首选不是唯一选择。问题明确时无需为了“方法完整”再读十卡；关键结论涉及因果或选择时，也不能只用故事线美化缺失的分析。方法之间可以反复往返，不强制一遍串行走完。

## 三种常见任务的起步组合
经营诊断：M02 找变化位置，M04 比较解释，M03 支撑判断，再用 M08/M10 写成主线。
方案选择：M05 比较真实路线；需要解释作用链时用 M04；对决定性未知用 M06；M07/M08 组织答案。
知识讲解：M09 对齐学习任务与先备知识，组织示范、边界和迁移；M03 保证解释成立，M10 删无关重复。

这些组合是建议，不是必须提交的产物数量。例行进展通报可以只说明目标、变化、影响和待决项；公司能力介绍可以围绕任务匹配、能力机制与适用经验组织。

## 信息不足仍然往前写
可直接复算的先算，缺原始分母的不算；可以解释原理但缺结果数据的，写清作用机制和条件；多解释仍兼容的，给最有区分力的下一观察；已有方向但成本未知的，写定性权衡和待确认成本项。不得把样例数字、常识先验权重或模型补出的客户事实填进空位。缺结果数据不自动使机制说明成为待验收益主张；仅在声称效果、收益或以其作投资判断时补充对应假设和验证办法。

## 什么时候读完整案例
在方法操作不熟悉、第一次写该类核心页面、或修稿需要看到完整正文时，选一个相近案例。先读 input，再读 after 与方法讲解；before 用于发现失败方式。复制的是比较和论证动作，不是数字、术语或结论。所有相关文件必须进入本次合法读取清单。

## 什么时候停止分析
当本次允许范围内的受众问题已有可用回答，核心判断的依据与条件明确，未决项不会被伪装成结论，即转入写作。不是等所有未知消失。若用户只要策划，到策划成果停止；只要口播或设计，不重启诊断。
