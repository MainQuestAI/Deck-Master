# Deck Master · 页面层级优化样页 (20261023) React 前端系统

本项目基于 OpenDesign 原型设计（`deck-master-ui-hierarchy-samples-20261023`）进行 100% 视觉与交互复刻，采用 React 18 + Vite 6 现代化工程栈重构。

## 🎯 核心特性与复刻范围

- **8 大完整工作面 (S00–S07)**：
  - **S00 所有项目 (Projects Matrix)**：项目矩阵卡片、状态标注（当前打开、已归档、制作中、路径失效）、短流程新建与本地目录演示。
  - **S01 制作总览 (Overview & Metrics)**：生产进度指标带（逐页稿/原图/SVG/PPT）、首要推进推荐横幅、次要快捷筛选操作、逐页制作进度矩阵表格。
  - **S02 内容与页序 (Content & Hierarchy)**：逐页稿与页序、章节大纲计划、4 份来源事实材料、章节大纲左侧过滤轨、页面多选与批量操作、键盘 `Alt+↑/↓` 逐页调序与脏状态撤销/应用横幅。
  - **S03 整稿画廊 (Gallery View)**：网格画板（Grid）与连续长卷（Continuous Reading）双视图、原图/SVG/逐页稿产物层切换、全量/候选筛选、一键启动全屏放映。
  - **S04 风格校准 (Style Calibration)**：4 阶段推进状态（参考目标、确认规范、试作采用、全稿扩展）、16:9 画板基准视效（支持 80% 安全区、三分构图网格、12 列版心标尺开关）、Token 规范检测列表。
  - **S05 任务与交付 (Delivery Center)**：四大业务分区（进行中任务、待决定事项、版本记录与恢复基准、交付文件包导出门禁）。
  - **S06 单页工作区 (Deep Page Reader)**：正文排印阅读与 16:9 画板预览互切、段落批注气泡与审阅卡片联动、右侧关联事实与产物进度/审阅统计轨。
  - **S07 候选比较 (Candidate Adoption)**：并排比对（Side-by-Side）与交互式卷帘滑块透视（Curtain Split Slider，支持 12%/50%/88% 快捷透视）、文本增删 Diff 高亮、一键决定（保留当前稿 R08 或采用候选升级至 R09）。

- **5 大共享交互容器 (U01–U05)**：
  - **U01 全屏放映预览 (Presentation)**：支持 16:9 响应式等比缩放、键盘 `←`/`→`/`Space`/`Esc` 操控、缩略导轨（`T` 键）、自动轮播（`P` 键，4.5s）、产物图层切换。
  - **U02 段落审阅气泡 (Review Bubbles)**：段落级批注列表、身份切换、采纳修改建议并实时同步正文、标记已解决与删除。
  - **U03 指挥台快捷搜索 (⌘K Spotlight)**：全局呼出、工作面导航跳转、全项目 30 页逐页全文极速检索直达。
  - **U04 抽屉系统 (Editor & Panels Drawer)**：480px / 880px 宽度伸缩、正文在线编辑与字数统计、关联材料摘录、修改页名、页序变动预览、事项清单、版本快照、设计规范。
  - **U05 状态反馈 (Toast)**：轻量非阻塞操作提醒（3.4s 自动关闭）。

- **未联调后端功能的视觉展示策略**：
  - 原型中存在但后台尚未包含的功能均完整渲染，并以角标 `[演示]` / `[待联调]` / `[等待前置]` 或置灰禁用态清晰表达其样板状态，兼顾 100% 视觉对齐与真实产品诚实性。

## 🛠️ 运行、预览与验证命令

### 1. 安装依赖
```bash
# 在 Deck-Master 前端目录
cd frontend
npm install

# 或者在 OpenDesign 项目本地目录
cd '/Users/dingcheng/Library/Application Support/Open Design/namespaces/release-stable/data/projects/deck-master-ui-hierarchy-samples-20261023'
npm install
```

### 2. 本地开发服务器启动 (HMR)
```bash
npm run dev
# 默认启动于 http://localhost:5173/，支持秒级热重载
```

### 3. 生产环境构建打包 (Build)
```bash
npm run build
# 执行 Vite Rollup 树摇打包，输出至 dist/
```

### 4. 预览生产环境产物 (Preview)
```bash
npm run preview
# 启动本地生产预览服务进行最终验收
```

## ⌨️ 全局交互快捷键一览

| 快捷键 | 作用范围 | 功能说明 |
| :--- | :--- | :--- |
| `⌘K` / `Ctrl+K` | 全局 | 呼出 / 关闭 Command Palette 指挥台搜索 |
| `Esc` | 全局 | 关闭弹窗、关闭抽屉、退出全屏放映模式 |
| `P` | 画廊 / 单页 | 一键进入当前页全屏放映预览模式 |
| `T` | 全屏放映中 | 开关底部 30 页缩略导轨横向托盘 |
| `Space` / `→` | 全屏放映中 | 步进下一页 |
| `←` | 全屏放映中 | 步退上一页 |
| `Alt+↑` / `Alt+↓` | S02 内容页序 | 对焦在页面行时，上下微调页面顺序 |
